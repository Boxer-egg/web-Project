# 餐饮盈利计算器 — 图形化展示需求文档

## 概述

在现有「餐饮盈利计算器」右侧结果区域新增图形化展现，让用户更直观地理解成本结构和盈利拐点。

---

## 一、核心结果 — 图形化展示

### 1.1 成本结构饼图

**数据来源**：月固定成本的三项构成

| 项目 | 数据变量 | 图示颜色 |
|------|----------|----------|
| 每月有效房租 | `effectiveMonthlyRent` | `#3b82f6`（蓝） |
| 每月人工 | `monthlyLabor` | `#f59e0b`（橙） |
| 水/电/杂费 | `monthlyUtilities` | `#22c55e`（绿） |

**图表类型**：环形饼图（Donut Chart）

**位置**：核心结果卡片底部，`metric-grid` 下方

**交互**：
- 悬停显示具体数值和占比百分比
- 中心显示总计文字"月固定成本 ¥X"

**视觉效果**：
- 图表尺寸约 240×240px
- 使用 Canvas 绘制，不引入第三方图表库
- 三区块按数据占比自动计算弧度

### 1.2 盈亏构成柱状图

**数据来源**：日盈亏平衡的各项

| 项目 | 数据变量 | 图示颜色 |
|------|----------|----------|
| 日固定成本 | `dailyFixedCost` | `#ef4444`（红） |
| 日盈亏平衡营业额 | `dailyBreakEvenRevenue` | `#f59e0b`（橙） |
| 保本日单数（辅助轴） | `dailyBreakEvenOrders` | `#3b82f6`（蓝） |

**图表类型**：横向柱状图（Horizontal Bar Chart）

**位置**：核心结果卡片内，**替换现有**的 `metric-grid` 中部分指标卡片

**设计细节**：
- 左右双轴：左轴显示金额（元），右轴显示单数
- 每根柱子末端标注具体数值
- 日盈亏平衡营业额柱子上方标注「保本线」

## 二、目标经营测算 — 盈利拐点折线图

### 2.1 图表概述

**图表类型**：双线折线图（Line Chart）

**X 轴**：日均单数（0 ~ max(保本日单数×2, 目标日单数×1.5)）

**Y 轴**：金额（元）

**两条折线**：

| 折线 | 含义 | 颜色 | 线条样式 |
|------|------|------|----------|
| 月净利润线 | 不同日单数对应的月净利润 | `#22c55e`（盈利） / `#ef4444`（亏损） | 粗实线 |
| 零利润线 | y=0 参考线 | `#9ca3af`（灰） | 虚线 |

### 2.2 关键标注点

需要**自动标注**以下关键点：

| 标注点 | X 值 | Y 值 | 图标 | 文字 |
|--------|------|------|------|------|
| 保本点 | `dailyBreakEvenOrders` | 0 | 🔴 圆点 | "保本线：X 单/天" |
| 目标点 | `targetDailyOrders` | `targetMonthlyNetProfit` | ⭐ 星标 | "目标：X 单/天，月利润 ¥Y" |

### 2.3 交互细节

- 图表上方显示滑块或输入框，用户可拖拽/输入日单数，实时看到对应利润
- 图表上有一条**竖直虚线**跟随当前选择的日单数
- 图表下方显示当前日单数对应的：
  - 日营收
  - 月营收
  - 月毛利
  - 月净利润

### 2.4 数据点计算

X 轴取 20 个等距采样点（从 0 到 X 轴最大值）：

```
对于每个采样点 dailyOrders：
  dailyRevenue = dailyOrders × avgTicket
  monthlyRevenue = dailyRevenue × 30
  monthlyGrossProfit = monthlyRevenue × grossMargin
  monthlyNetProfit = monthlyGrossProfit - monthlyFixedCost
```

### 2.5 位置

**替换**当前「目标经营测算」卡片中的部分内容。该卡片上方保留「保本日单数」和「目标日单数」两个关键数值，下方全部替换为折线图。

## 三、技术方案

### 3.1 实现方式

- 使用原生 Canvas API 绘制所有图表
- 在 `RestaurantProfitCalculator.vue` 中新增 4 个 computed 或函数：
  - `drawCostPieChart(canvas)` — 绘制成本饼图
  - `drawBreakEvenBarChart(canvas)` — 绘制盈亏柱状图
  - `drawProfitLineChart(canvas)` — 绘制盈利折线图
  - `generateLineData()` — 生成折线图 20 个数据点

### 3.2 Canvas 尺寸与 DPI

- 所有 Canvas 使用 2x 分辨率（retina），CSS 尺寸与 Canvas 尺寸独立
- 饼图：CSS 240×240，Canvas 480×480
- 柱状图：CSS 400×200，Canvas 800×400
- 折线图：CSS 600×340，Canvas 1200×680

### 3.3 不引入外部依赖

保持与现有项目一致（纯 Canvas + 手动绘制），不引入 Chart.js、ECharts 等第三方图表库，减少打包体积。

## 四、布局调整

现有右侧结果面板布局：

```
┌─ 核心结果 ────────────────────┐
│  [建店成本] [有效房租] ...    │  ← metric-grid（保留）
│  ┌─ 成本饼图 ──┐ ┌─ 柱状图 ──┐ │  ← 新增（左右并排）
│  │              │ │            │ │
│  └──────────────┘ └───────────┘ │
└────────────────────────────────┘

┌─ 目标经营测算 ────────────────┐
│  保本日单数: X  |  目标日单数: Y │ ← 保留关键数值
│  ┌─ 盈利拐点折线图 ──────────┐  │
│  │                            │  │  ← 新增
│  │   (折线 + 标注)            │  │
│  │                            │  │
│  └────────────────────────────┘  │
│  日单数滑块: [========] XX 单     │  ← 新增交互
│  日营收: X  月营收: Y  月净利: Z │  ← 新增跟随数值
└────────────────────────────────┘
```

## 五、验收标准

1. 饼图正确展示三项成本占比
2. 柱状图正确展示日固定成本 vs 盈亏平衡营业额
3. 折线图 X 轴为日单数、Y 轴为月净利润
4. 折线图上标注保本点和目标点
5. 用户拖拽滑块时折线图上的竖线跟随移动
6. 所有图表在移动端（< 900px）自适应为单列堆叠
7. Canvas 在 retina 屏幕上清晰无锯齿
8. 填写必填字段后图表自动更新，不填时为空白占位
9. 与现有「保存图片」功能兼容（图表也出现在导出的 PNG 中）
