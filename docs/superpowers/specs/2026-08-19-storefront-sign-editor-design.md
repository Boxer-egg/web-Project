# 门头编辑器设计文档

## 背景

餐饮店铺确定后，店主通常需要设计门头招牌。现有工具缺少一个面向普通店主的轻量门头排版工具：输入招牌物理尺寸，拖拽文字与 Logo，实时查看对齐、间距与整体效果，并导出带尺寸标注的工程图或 PNG 预览。

## 目标

- 新增独立工具页面「门头编辑器」。
- 支持输入招牌物理尺寸，生成按比例画布，并提供预设尺寸/比例模板。
- 支持添加大字（店名）和小字（副标题/标语），可自定义字体、颜色、加粗、竖排。
- 支持上传 Logo，提供去底色、颜色替换、缩放、旋转、拖拽摆放。
- 提供吸附对齐、网格线、安全边界等辅助排版功能。
- 实时显示元素到画布四边的物理距离，以及元素之间的物理间距。
- 支持导出带尺寸标注的工程图与 PNG 图片，可选按真实 DPI 导出。
- 适配移动端，方便店主在平板或手机上快速比划。

## 非目标

- 不引入第三方设计软件或后端服务，全部在浏览器端完成。
- 不实现复杂的图层管理（如锁定、隐藏、多页面）。
- 不提供云端保存/账号系统；保存仅使用浏览器本地存储或本地文件导出。
- 不实现高级图像处理（如 AI 抠图、矢量编辑、3D 预览）。
- 不直接对接打印店或生成打印工单。

## 功能设计

### 1. 页面入口

- **工具名称**：门头编辑器
- **路由路径**：`/tools/storefront-sign-editor`
- **侧边栏分组**：商业测算（与餐饮盈利计算器、餐饮反向调研同组）
- **首页卡片**：在「商业」分类中展示

### 2. 画布设置

#### 2.1 尺寸输入

- 输入项：宽度、高度，单位默认为 **厘米（cm）**。
- 数值范围：宽度 10 cm ~ 1000 cm，高度 10 cm ~ 500 cm。
- 支持锁定宽高比（可选）。
- 提供「默认尺寸」按钮，默认值为 **300 cm × 80 cm**（常见餐饮门头）。

#### 2.2 预设模板

| 预设名称 | 尺寸（宽 × 高） | 适用场景 |
|---|---|---|
| 标准横版门头 | 300 × 80 cm | 普通餐饮店 |
| 小型横版 | 200 × 60 cm | 档口/小店 |
| 大型横版 | 500 × 120 cm | 旗舰店 |
| 竖版灯箱 | 80 × 200 cm | 立式招牌 |
| 方形灯箱 | 100 × 100 cm | 正方形招牌 |
| 自定义 | 用户输入 | 任意尺寸 |

- 选择预设后自动填充宽高。
- 画布按屏幕可用空间自适应缩放，角落显示当前缩放比例（如 10%）。

### 3. 文字元素

#### 3.1 文字类型

- **大字**：默认字号高 40 cm，用于店名。
- **小字**：默认字号高 12 cm，用于副标题/标语。
- 每个元素独立：可添加多个大字/小字，可删除。

#### 3.2 文字属性

| 属性 | 选项/范围 | 默认值 |
|---|---|---|
| 内容 | 文本输入 | 大字默认「店名」，小字默认「副标题」 |
| 字体 | 系统默认 / 宋体 / 黑体 / 楷体 / 微软雅黑 / 思源黑体等 | 系统默认 |
| 颜色 | 颜色选择器 | #000000 |
| 加粗 | 开关 | 关 |
| 竖排 | 开关 | 关 |
| 字号 | 物理高度 5 cm ~ 200 cm | 大字 40 cm，小字 12 cm |

- 竖排时，文字从上到下、从右到左排列。
- 不支持描边、阴影、背景色块。
- 多语言字体支持：通过系统字体栈覆盖中文、英文、日文、韩文等。

### 4. Logo 元素

#### 4.1 上传

- 支持格式：PNG、JPG、SVG。
- 文件大小限制：10 MB。
- 上传后显示在画布中央。

#### 4.2 编辑

- 拖拽移动。
- 角点拖拽缩放（保持宽高比）。
- 旋转手柄：支持 0° ~ 360° 旋转，步进 1°。
- 删除按钮。

#### 4.3 图像处理

- **去底色**：将图片中接近白色的像素（如 #FFFFFF ± 阈值）设为透明。
  - 阈值可调，默认 30。
  - 仅对 PNG/JPG 有效；SVG 跳过。
- **颜色替换**：将 Logo 的主色替换为选定的颜色。
  - 提供颜色选择器。
  - 对 SVG 支持直接改 fill；对位图使用 Canvas 像素替换（基于主色+容差）。

### 5. 辅助排版

#### 5.1 网格线

- 开关按钮：显示/隐藏。
- 默认关闭。
- 网格间距可设：5 cm / 10 cm / 20 cm / 50 cm。

#### 5.2 安全边界

- 开关按钮：显示/隐藏。
- 默认关闭。
- 安全边界宽度可设：5 cm / 10 cm / 15 cm / 20 cm。
- 以虚线框在画布内侧显示，提示文字/Logo 不应超出此区域。

#### 5.3 吸附对齐

- 自动吸附：拖拽元素靠近时，自动吸附到画布中心线、四边、网格线。
- 元素间吸附：两个元素靠近时，自动左/右/上/下/中对齐。
- 吸附阈值：物理距离 1 cm 内触发。
- 可开关：默认开启。

#### 5.4 辅助线

- 当选中某个元素时，显示从元素四边延伸到画布边缘的辅助虚线。
- 辅助线不可拖拽，仅用于视觉参考。

### 6. 间距与尺寸标注

#### 6.1 元素到画布边缘

- 选中元素时，显示元素边界到画布上/下/左/右边缘的物理距离。
- 显示位置：辅助线旁边或属性面板。

#### 6.2 元素之间间距

- 当两个元素都被选中，或鼠标悬停在两个元素之间时，显示它们之间的水平/垂直物理间距。
- 支持多元素间距链式显示。

#### 6.3 元素自身尺寸

- 选中元素时，属性面板显示元素当前的宽、高（物理尺寸）。

### 7. 导出

#### 7.1 导出带尺寸标注的工程图

- 在画布基础上叠加：
  - 画布外框尺寸标注（宽 × 高）。
  - 各元素边界尺寸线。
  - 元素到边缘、元素之间的间距标注。
- 导出格式：PNG。
- 背景可选：白色 / 透明。

#### 7.2 导出 PNG 预览图

- 仅导出当前画布视觉内容。
- 可选是否带网格/安全边界/辅助线。
- 可选背景色。

#### 7.3 DPI 设置

- 导出时提供「按真实 DPI 导出」复选框。
- 勾选后按 300 DPI 计算输出像素（1 cm ≈ 118 px）。
- 未勾选时按屏幕预览比例导出（适合快速分享）。

#### 7.4 文件名

- 默认：`门头设计_<宽度>x<高度>cm_<时间戳>.png`
- 示例：`门头设计_300x80cm_20260819.png`

### 8. 保存与加载

- 不做云端保存。
- 支持「保存到本地」：将当前设计状态导出为 JSON 文件。
- 支持「加载本地设计」：导入 JSON 文件恢复状态。
- 同时自动保存到 `localStorage`，刷新页面可恢复。

### 9. 移动端适配

- 桌面端：左侧画布，右侧属性面板。
- 移动端：
  - 顶部工具栏（添加文字、上传 Logo、显示设置、导出）。
  - 中间画布，支持双指缩放/平移。
  - 底部选中元素属性面板，可收起。

## 数据流

1. 用户设置招牌尺寸 → 计算画布 CSS 尺寸与物理像素比例。
2. 用户添加文字/Logo → 创建元素对象，存入响应式数组。
3. 用户拖拽/缩放/旋转 → 更新元素的位置、尺寸、旋转角度。
4. 辅助工具实时计算：吸附位置、间距标注、元素尺寸。
5. 导出时：
   - 在离屏 Canvas 上绘制背景 → 网格/安全边界 → Logo → 文字 → 尺寸标注。
   - 按导出选项设置 Canvas 像素尺寸与 DPI。
   - 触发浏览器下载。

## 元素数据结构

```javascript
{
  id: string,           // 唯一标识
  type: 'text' | 'logo',
  name: string,         // 元素名称，如「店名」
  x: number,            // 左上角物理 x（cm）
  y: number,            // 左上角物理 y（cm）
  width: number,        // 物理宽度（cm）
  height: number,       // 物理高度（cm）
  rotation: number,     // 旋转角度（deg）

  // 文字特有
  text: string,
  fontSize: number,     // 物理字号高度（cm）
  fontFamily: string,
  color: string,
  bold: boolean,
  vertical: boolean,

  // Logo 特有
  src: string,          // Data URL 或 Object URL
  originalSrc: string,
  removeBackground: boolean,
  removeThreshold: number,
  replaceColor: boolean,
  targetColor: string,
  replacementColor: string
}
```

## 错误处理

- 上传非图片文件：提示「请上传 PNG / JPG / SVG 格式图片」。
- 上传文件过大：提示「图片过大，请选择 10MB 以内的图片」。
- 输入非法尺寸：自动修正为最小/最大值，并提示。
- Canvas 不支持：提示「当前浏览器不支持图片处理，请更换浏览器」。
- 导出失败：提示「图片生成失败，请重试」。

## 性能考虑

- Canvas 重绘使用防抖（100ms），避免频繁拖拽时全量重绘。
- Logo 处理（去底色、颜色替换）在 Web Worker 中进行，避免阻塞主线程。
- 大图片处理时显示加载提示。
- 导出真实 DPI 时，若计算出的像素过大（如超过 8192px），提示用户并建议降低 DPI 或尺寸。

## 验收标准

1. 侧边栏和首页出现「门头编辑器」入口。
2. 可输入招牌尺寸，选择预设后自动填充。
3. 可添加大字/小字，修改内容、字体、颜色、加粗、竖排。
4. 可上传 Logo，缩放、旋转、拖拽，支持去底色和颜色替换。
5. 网格线、安全边界、吸附对齐、辅助线均可开关并生效。
6. 选中元素时显示到画布四边的距离和自身尺寸。
7. 多选或悬停时显示元素之间的物理间距。
8. 可导出带尺寸标注的工程图 PNG。
9. 可导出普通 PNG 预览图，可选真实 DPI。
10. 支持保存/加载本地 JSON 设计文件，并自动保存到 localStorage。
11. 移动端布局正常，画布可双指缩放，属性面板可收起。
12. 非图片文件和超大文件上传时给出明确错误提示。

## 技术实现

### 新增/修改文件

- `frontend/src/views/tools/StorefrontSignEditor.vue`
  - 页面组件：状态管理、画布渲染、元素编辑、导出逻辑。
- `frontend/src/logic/storefrontSign.js`
  - 纯逻辑：尺寸换算、吸附计算、间距标注、导出 Canvas 绘制。
- `frontend/src/utils/imageProcessing.js`
  - Logo 去底色、颜色替换等图像处理函数。
- `frontend/src/router/index.js`
  - 注册 `/tools/storefront-sign-editor` 路由。
- `frontend/src/components/Sidebar.vue`
  - 在「商业测算」分组新增入口。
- `frontend/src/views/Home.vue`
  - 在「商业」分类新增首页卡片。
- `frontend/functions/_shared/routes-meta.json`
  - 补充新路由的 title/description（由构建脚本生成）。

### 依赖

- 不引入第三方图表/设计库。
- 使用原生 HTML5 Canvas、FileReader、Blob API。
- 使用 Web Worker 处理 Logo 像素（可选，可在 Worker 不可用時回退到主线程）。
- 使用 `@vueuse/core` 的 `useStorage`、`useDebounceFn`。

## 回滚计划

- 本次改动新增独立 Vue 组件和路由配置，不影响现有工具。
- 若出现问题，可直接移除路由注册和侧边栏/首页入口，回滚到改动前状态。
