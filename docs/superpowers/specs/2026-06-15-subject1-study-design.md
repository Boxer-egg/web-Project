# 科目一系统学习页面设计文档

**日期**：2026-06-15  
**功能**：新增 `/driving/license-study` 科目一系统学习页面  
**参考**：用户提供的知乎文章（未能直接获取，按通用科目一知识体系设计）

---

## 一、目标

为驾考刷题工具增加一个独立、系统化的科目一学习页面，帮助用户在刷题前先建立知识体系。页面采用课程式向导，按章节逐步学习，学完可跳转到对应章节练习。

---

## 二、用户可见设计

### 2.1 页面结构

- **独立页面**：`/driving/license-study`
- **侧边栏入口**：驾考刷题下方新增「科目一学习」
- **首页**：展示章节列表、总进度、继续学习按钮
- **学习页**：顶部进度条 + 当前知识点 + 底部导航

### 2.2 学习流程

1. 进入页面看到章节概览（12 个左右章节）。
2. 点击「开始学习」或未完成章节进入课程向导。
3. 每页展示一个知识点：标题、图文内容、速记口诀/要点。
4. 底部按钮：上一章、练习本章、下一章。
5. 点击「练习本章」跳转到刷题页并携带 `chapter` 参数。
6. 学完所有章节显示总结页。

### 2.3 交互细节

- 进度条显示已完成知识点比例。
- 已学完章节在概览页标记完成。
- 支持键盘左右方向键切换知识点。
- 移动端底部按钮固定，便于单手操作。

---

## 三、学习内容范围

按用户确认的 4 大模块组织：

| 模块 | 章节示例 |
|------|---------|
| 交通信号与标志 | 警告标志、禁令标志、指示标志、标线、信号灯、交警手势 |
| 驾驶证管理规定 | 申领、实习期、记分、换证补证、准驾车型 |
| 道路通行规则 | 限速、超车、会车、路口、高速公路、特殊路段 |
| 违法处罚与安全驾驶 | 酒驾、灯光使用、停车规定、事故处理、应急处理 |

每个章节包含 2-6 个知识点，共约 30-50 个知识点。

## 四、技术设计（已自主确认）

### 4.1 文件与路由

| 文件 | 说明 |
|------|------|
| `frontend/src/views/tools/DrivingLicenseStudy.vue` | 学习页面主组件 |
| `frontend/src/composables/useDrivingStudy.js` | 学习数据加载、进度管理 |
| `frontend/public/data/driving-license-study.json` | 章节化学习内容 |
| `frontend/src/router/index.js` | 注册 `/driving/license-study` |
| `frontend/src/components/Sidebar.vue` | 新增侧边栏入口 |

### 4.2 数据结构

```json
{
  "meta": {
```

### 4.3 状态管理

- 学习进度保存到 `localStorage`，key：`driving-study-progress`
- 存储已完成知识点 ID 数组，便于跨会话恢复。
- 进度在概览页和学习页同步。

### 4.4 与刷题页集成

- 「练习本章」跳转链接：`/driving/quiz?mode=sequential&chapter=交通标志`
- 刷题页需支持按 `chapter` URL 参数筛选题目（本次一并实现）。

---

## 五、错误处理

- 学习 JSON 加载失败：显示错误信息 + 重试按钮。
- 图片加载失败：隐藏图片，不影响文本阅读。
- localStorage 写入失败：降级为仅当前会话保留进度。

---

## 六、范围外（YAGNI）

- 暂不支持视频、动画。
- 暂不做学习时长统计。
- 暂不支持用户笔记或收藏知识点。
- 科目四学习内容暂不纳入。

---

## 七、验收标准

- [ ] 侧边栏有「科目一学习」入口，点击进入新页面。
- [ ] 页面展示章节概览和总进度。
- [ ] 进入学习后，每页展示一个知识点，可上一章/下一章切换。
- [ ] 点击「练习本章」能跳转到刷题页并筛选对应章节题目。
- [ ] 进度在刷新后保留。
- [ ] 移动端布局正常。
