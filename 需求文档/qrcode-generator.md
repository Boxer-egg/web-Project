# 二维码生成器

## 功能概述
将文本或 URL 转换为可扫描的二维码图片，支持自定义尺寸、颜色、纠错级别，并可下载为 PNG 图片。

## 输入
- 文本输入框（textarea）：输入要编码的内容（文本或 URL）
- 尺寸选择：128px / 256px / 512px / 1024px
- 纠错级别：L(7%) / M(15%) / Q(25%) / H(30%)
- 颜色配置：
  - 前景色（二维码方块颜色，默认黑色）
  - 背景色（默认白色）
- 边距（Quiet Zone）：1~4 个模块

## 操作按钮
1. **生成** — 生成二维码图片
2. **下载 PNG** — 下载二维码图片
3. **复制内容** — 复制输入的原始内容
4. **清空** — 清空输入
5. **加载示例** — 填入示例 URL

## 输出
- 二维码图片预览区（居中展示）
- 内容长度提示：显示当前内容字符数（二维码容量限制提示）
- 纠错级别提示：根据内容长度推荐合适的纠错级别

## 状态流转（逻辑/交互）
```
用户进入页面
    │
    ├── [加载示例] ──→ 填入示例 URL ──→ 自动生成
    │
    └── 用户输入内容
        │
        ├── 实时显示字符数
        │   └── 超过当前纠错级别容量 ──→ 提示 "内容过长，建议提高纠错级别"
        │
        ├── 调整尺寸/颜色/纠错级别
        │   └── 如有内容，实时重新生成（防抖 300ms）
        │
        ├── 点击 [生成]
        │   ├── 输入为空 ──→ 提示 "请输入内容"
        │   ├── 内容过长超出最高纠错级别 ──→ 提示 "内容超出二维码最大容量"
        │   └── 正常 ──→ 生成二维码图片
        │
        └── 点击 [下载 PNG]
            └── 下载当前二维码为 PNG 图片
```

## 边界情况
- 输入空字符串：提示 "请输入内容"
- 输入超长内容（>H 级别最大容量约 2953 字节）：提示 "内容过长，无法生成二维码"
- 输入包含中文：正确编码（QR Code 支持 UTF-8）
- 输入包含 emoji：正确编码
- 前景色和背景色相同：提示 "前景色和背景色不能相同"
- 背景色为透明：支持 rgba 透明背景
- 尺寸极大（1024px）：在低性能设备上可能生成较慢，显示 "生成中..."
- 边距为 0：技术上可行，但扫描识别率可能下降，提示 "建议至少保留 1 格边距"

## 错误处理（异常）
| 场景 | 处理方式 |
|:---|:---|
| 输入为空 | 提示 "请输入要生成二维码的内容" |
| 内容超出容量 | 提示 "内容过长（当前 X 字符，最大支持 Y 字符）" |
| 前后景色相同 | 提示 "前景色和背景色不能相同" |
| 生成失败 | 提示 "生成失败，请检查输入内容" |
| 下载失败 | 提示 "下载失败"，提供右键保存图片的备选方案 |

## 本地存储策略
- 保存最后一次输入的内容
- 保存尺寸、颜色、纠错级别配置
- 不保存生成的图片

## 响应式适配
- 桌面端：左右分栏，预览区二维码居中展示
- 移动端：上下分栏，二维码预览区占满宽度
- 颜色选择器在移动端使用原生 input[type=color]

## 技术备注
- 使用 `qrcode` npm 库生成二维码 Data URL
- 需要将该库添加到项目依赖中
