# Hash 计算器

## 功能概述
对输入的文本或文件计算多种哈希值（MD5、SHA1、SHA256、SHA512），支持实时计算和批量算法同时输出。

## 输入
- 文本输入框（textarea）：输入任意文本
- 文件上传区域（拖拽或点击）：上传文件计算哈希
- 算法选择：多选框（MD5、SHA1、SHA256、SHA512）

## 操作按钮
1. **计算** — 对输入内容计算选中的哈希值
2. **文件上传** — 选择文件计算哈希
3. **复制结果** — 每个哈希结果旁有独立复制按钮
4. **复制全部** — 以 key: value 格式复制所有结果
5. **清空** — 清空输入和结果
6. **加载示例** — 填入示例文本

## 输出
- 结果列表：每个选中的算法一行
  - 算法名称 + 哈希值（可复制）
  - 字符数/字节数统计
- 文件模式额外显示：文件名、文件大小

```
|                  |                  |

```

## 状态流转（逻辑/交互）
```
用户进入页面
    │
    ├── 默认选中全部四种算法
    │
    ├── [加载示例] ──→ 填入示例文本 ──→ 自动计算
    │
    ├── 文本模式
    │   ├── 用户输入文本
    │   ├── 选择算法（可多选）
    │   ├── 点击 [计算]
    │   │   ├── 输入为空 ──→ 提示 "请输入内容"
    │   │   └── 输入有内容 ──→ 实时计算并展示结果
    │   └── 点击复制 ──→ 复制对应哈希值
    │
    └── 文件模式
        ├── 用户拖拽或选择文件
        ├── 自动开始计算（显示进度）
        ├── 大文件（>10MB）──→ 显示 "正在计算..." 进度提示
        └── 计算完成 ──→ 展示结果
```

## 边界情况
- 输入空字符串：计算空字符串的哈希值（合法结果，不报错）
- 输入包含中文/emoji：正确计算 UTF-8 编码后的哈希
- 文件为空文件（0 字节）：计算空内容的哈希
- 文件 >50MB：提示 "文件较大，计算可能需要一些时间"
- 未选择任何算法：提示 "请至少选择一种哈希算法"
- 全部取消勾选后再计算：提示并阻止
- 文本和文件同时存在：优先以当前激活的模式为准

## 错误处理（异常）
| 场景 | 处理方式 |
|:---|:---|
| 输入为空时点击计算 | 提示 "请输入文本或上传文件" |
| 未选择任何算法 | 提示 "请至少选择一种哈希算法" |
| 文件读取失败 | 提示 "文件读取失败，请重试" |
| 文件过大（>100MB） | 提示 "文件过大，建议分割后计算" |
| 计算异常 | 提示 "计算出错：" + 错误信息 |
| 复制失败 | 提示手动复制 |

## 本地存储策略
- 保存文本输入内容
- 保存算法选择偏好
- 不保存文件（文件无法存储）

## 响应式适配
- 桌面端：左右分栏，算法选择区在输入区上方
- 移动端：上下分栏，算法选择横向排列可滚动
- 哈希结果在移动端自动换行显示
