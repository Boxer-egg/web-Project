# 文本差异对比工具

## 功能概述
比较两段文本的差异，以行级或字符级高亮展示新增、删除和修改的内容。

## 输入
1. 原文本输入框（左侧 textarea）：输入原始文本
2. 对比文本输入框（右侧 textarea）：输入修改后的文本

## 操作按钮
1. **对比差异** — 执行 diff 计算并展示结果
2. **交换内容** — 交换左右两个输入框的内容
3. **复制差异** — 复制差异结果
4. **清空** — 清空两侧输入
5. **加载示例** — 填入两段有差异的示例文本

## 输出
- 差异结果展示区：
  - 删除的行：红色背景，行首标记 `-`
  - 新增的行：绿色背景，行首标记 `+`
  - 未变的行：正常显示
  - 行内差异：同一行中修改的部分用深色高亮
- 统计信息：新增行数、删除行数、修改行数

## 界面布局
```
+------------------+------------------+
|   原文本          |   对比文本        |
|   [            ]  |   [            ] |
|   [            ]  |   [            ] |
|                  |                  |
|   [清空] [示例]   |   [交换内容]      |
|                  |                  |
+----------[对比差异]-----------------+
|           差异结果                   |
|   - 删除的行（红色）                |
|   + 新增的行（绿色）                |
|   未变的行                          |
|                                     |
|   统计: +5行 -3行                   |
|   [复制差异]                        |
+-------------------------------------+
```

## 功能细节
- 支持行级 diff 和字符级 diff 切换
- 结果区域支持滚动同步（行号对齐）
- 差异统计实时更新
- 支持忽略空白字符的选项

## 状态流转
```
用户进入页面
    │
    ├── [加载示例] ──→ 填入两段有差异的示例文本
    │
    ├── 用户在左侧输入原文本
    │   └── 实时保存到 localStorage
    │
    ├── 用户在右侧输入对比文本
    │   └── 实时保存到 localStorage
    │
    ├── 用户点击 [对比差异]
    │   ├── 任一侧为空 ──→ 提示 "请输入两段文本进行对比"
    │   └── 两侧均有内容 ──→ 执行 diff 算法，展示结果
    │
    ├── 用户点击 [交换内容]
    │   └── 左右输入框内容互换，若已对比则重新执行对比
    │
    ├── 用户切换 diff 模式（行级/字符级）
    │   └── 重新执行对比，展示不同粒度结果
    │
    └── 用户点击 [复制差异]
        └── 以带 +/- 标记的文本格式复制到剪贴板
```

## 错误处理
| 场景 | 处理方式 |
|:---|:---|
| 点击对比时一侧为空 | 提示 "请输入原文本和对比文本" |
| 两段文本完全相同 | 结果区显示 "两段文本完全相同"，高亮统计为 0 |
| 文本极长（>10万行） | 提示 "文本较长，对比可能需要一些时间"，执行对比 |
| 复制失败 | 提示手动复制 |

## 边界情况
- 原文本为空，对比文本有内容：所有行标记为新增（绿色）
- 原文本有内容，对比文本为空：所有行标记为删除（红色）
- 两侧均为空：提示 "请输入内容"
- 行内 diff：同一行中只有部分字符变化时，用深色高亮变化部分，整行背景色较浅
- 忽略空白字符模式：对比前先去除首尾空白，行内多余空格视为相同
- 换行符差异（LF vs CRLF）：默认视为相同（或提供选项）
- Unicode 字符差异：逐字符精确对比
- diff 结果过长：支持虚拟滚动或分页（首批可先做普通滚动）

## 本地存储策略
- 分别保存左侧原文本和右侧对比文本
- 保存 diff 模式偏好（行级/字符级）
- 保存 "忽略空白" 选项状态
- 页面刷新后恢复两侧内容和选项

## 响应式适配
- 桌面端：左右分栏输入，下方全宽展示 diff 结果
- 移动端：输入区上下堆叠（原文本上，对比文本下），diff 结果全宽展示
- diff 结果在移动端缩小字号，减少左右空白
