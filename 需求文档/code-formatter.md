# 代码格式化工具

## 功能概述
对 JavaScript、CSS、HTML、JSON 等代码进行格式化（美化）或压缩（minify）处理。

## 输入
1. 语言选择下拉框：JavaScript / CSS / HTML / JSON
2. 代码输入框（textarea）：输入待处理的代码
3. 操作模式选择：格式化（美化）/ 压缩（minify）

## 操作按钮
1. **格式化** — 按规范缩进排版代码
2. **压缩** — 移除所有不必要的空白和换行
3. **复制结果** — 复制输出代码
4. **清空** — 清空输入输出
5. **加载示例** — 根据所选语言填入示例代码

## 输出
- 代码输出框：展示格式化或压缩后的代码
- 行号显示（格式化模式下）
- 字符数统计：输入长度 vs 输出长度
- 压缩率（压缩模式下）：显示减少了多少百分比

## 界面布局
```
+------------------+------------------+
| 语言: [JS ▼]      |                  |
| 模式: [格式化●]   |   输出区域        |
|       [压缩  ]   |   (带行号/纯文本) |
|                  |                  |
|   输入代码        |   [复制结果]      |
|   [            ]  |   字符: 120 → 80  |
|   [            ]  |   压缩率: 33%     |
|   [            ]  |                  |
|   [格式化] [压缩] |                  |
|   [清空] [示例]   |                  |
+------------------+------------------+
```

## 功能细节
- 支持语言：JavaScript、CSS、HTML、JSON
- 格式化缩进支持 2/4 空格切换
- 格式化模式显示行号
- 压缩模式显示压缩率
- 语法错误时给出大致错误位置提示（非严格校验，尽量容错）

## 状态流转
```
用户进入页面
    │
    ├── 默认语言：JavaScript
    │
    ├── 用户选择语言（JS/CSS/HTML/JSON）
    │   └── [加载示例] 按钮自动更新为对应语言的示例
    │
    ├── [加载示例] ──→ 填入对应语言的示例代码
    │
    ├── 用户输入代码
    │   └── 实时保存到 localStorage（按语言分别存储）
    │
    ├── 用户点击 [格式化]
    │   ├── 代码合法 ──→ 输出格式化后的代码 + 行号
    │   ├── 代码有语法错误 ──→ 尽量容错格式化，给出警告
    │   └── 代码为空 ──→ 提示 "请输入代码"
    │
    ├── 用户点击 [压缩]
    │   ├── 代码合法 ──→ 输出压缩后的单行代码 + 压缩率
    │   ├── 代码有语法错误 ──→ 尽量容错压缩，给出警告
    │   └── 代码为空 ──→ 提示 "请输入代码"
    │
    └── 用户切换缩进（2空格/4空格）
        └── 若输出区已有格式化结果，实时重新格式化
```

## 错误处理
| 场景 | 处理方式 |
|:---|:---|
| 输入为空 | 提示 "请输入代码" |
| 语法错误但能容错 | 输出格式化/压缩结果，顶部黄色警告 "可能存在语法问题" |
| 语法错误且无法处理 | 提示 "代码语法错误，请检查"，尽量给出错误位置 |
| 选择 JSON 语言但输入非 JSON | 尝试格式化，若完全无法解析则提示 "无效的 JSON" |
| 压缩率为 0% 或负数 | 显示 "已是最小体积" |
| 复制失败 | 提示手动复制 |

## 边界情况
- 输入已是格式化好的代码：再次格式化保持一致，不引入多余空行
- 输入已是压缩代码：格式化后正常展开
- HTML 中包含内联 CSS/JS：整体格式化，不区分内部内容
- 代码包含中文注释：正确保留，不乱码
- 代码包含 emoji：正确保留
- 超大代码（>1MB）：显示 "处理中..."，避免阻塞页面
- 不同语言的格式化规则：
  - JS：函数体缩进、对象对齐、分号处理
  - CSS：选择器分行、属性对齐、大括号位置
  - HTML：标签缩进、属性换行规则
  - JSON：键值对齐、数组元素缩进

## 本地存储策略
- 按语言分别存储用户输入的代码（key 为 `code-formatter-js`、`code-formatter-css` 等）
- 保存缩进偏好（2 空格 / 4 空格）
- 保存最近使用的语言

## 响应式适配
- 桌面端：左右分栏，输入输出各占 50%
- 移动端：上下分栏，输入在上（50%），输出在下（50%）
- 行号在移动端可隐藏（提供切换按钮）以节省空间
- 语言选择下拉框在移动端全宽展示
