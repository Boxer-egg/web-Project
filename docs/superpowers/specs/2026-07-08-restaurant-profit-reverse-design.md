# 餐饮反向调研计算器 · 功能设计文档

> **定位**：与现有「餐饮盈利计算器（正向）」配套使用。用户实地调研商圈同类快餐店时，往往只能问到单一经营数据；本工具通过该数据反推店铺日均单数、日营业额、月营业额、月净利润及翻台率，辅助评估竞品真实经营状况。

**目标用户**：准备开店或已开店，需要调研同商圈竞品的餐饮创业者。

**使用场景**：在店外观察、与店主/员工闲聊后，获得碎片化数据，借助估算参数还原完整经营画像。

---

## 全局约束

- 文档只描述功能与交互，不涉及具体代码实现。
- 计算结果必须明确标注「基于估算，仅供参考」。
- 所有输入必须允许为空或默认值，避免强制填写导致使用门槛提高。
- 交互风格与现有「餐饮盈利计算器」保持一致。

## 1. 核心功能

### 1.1 调研数据输入（三选一）

用户只能填写以下三项中的一项，作为反推起点：

| 模式 | 字段名称 | 含义 | 单位 |
|---|---|---|---|
| 模式 A | 日营业额 | 店铺平均每天卖出的金额 | 元/天 |
| 模式 B | 月净利润 | 店铺每月扣除成本后剩余的利润 | 元/月 |
| 模式 C | 日均客户数 | 店铺平均每天接待的顾客人数 | 人/天 |

**交互规则**：
- 页面顶部以单选按钮或标签页形式展示三种模式。
- 选中某模式后，仅该模式对应的输入框为可编辑状态；其余两项输入框置灰或隐藏。
- 切换模式时，当前已填数值保留但不再参与计算，待用户重新确认后刷新结果。

### 1.2 估算参数

无论选择哪种模式，用户都需填写以下估算参数：

| 参数 | 必填 | 默认值 | 说明 |
|---|---|---|---|
| 平均客单价 | 是 | 0 | 每单平均消费金额 |
| 毛利率 | 是 | 0 | 毛利占营收的比例，范围 0% ~ 100% |
| 月固定成本 / 年固定成本（二选一） | 是 | 0 | 店铺每月/每年的固定支出 |
| 座位数 | 否 | 0 | 填写后计算翻台率 |
| 客户→订单转化率 | 否 | 100% | 默认 1 位顾客 = 1 单；可调整，例如团体顾客时降低 |
| 每月营业天数 | 否 | 30 | 用于月与天之间的换算 |

**固定成本填写规则**：
- 提供「月固定成本」和「年固定成本」两个输入框，用户任填其一。
- 若填写年固定成本，系统自动换算为月固定成本参与计算：月固定成本 = 年固定成本 ÷ 12。
- 若两者都填，以最后修改的字段为准，另一字段自动同步换算后的值。

### 1.3 核心输出

统一展示以下结果，帮助用户形成对竞品的完整判断：

| 输出项 | 说明 |
|---|---|
| **日均单数** | 核心输出，店铺平均每天卖出的订单数 |
| 日营业额 | 店铺平均每天营业额 |
| 月营业额 | 店铺每月营业额 |
| 月净利润 | 店铺每月净利润 |
| 翻台率 | 日均单数 ÷ 座位数；未填座位数时不显示 |
| 客单价校验提示 | 若反推出的日均单数明显异常，给出提示 |

### 1.4 辅助功能

- **加载示例**：一键填入一组合理的竞品调研示例数据，方便用户理解使用方式。
- **清空**：重置所有输入为默认值。
- **下载结果图片**：将反推结果生成图片保存到本地，便于在微信群或笔记中分享。
- **切换正向测算**：提供入口跳转回现有「餐饮盈利计算器」。

## 2. 计算逻辑

所有模式最终都归一到「日均单数」和「日营业额」。

### 2.1 公共变量

- `avgTicket` = 平均客单价
- `grossMargin` = 毛利率（小数，如 60% = 0.6）
- `monthlyFixedCost` = 月固定成本（若用户填年固定成本，则先 ÷ 12）
- `seats` = 座位数
- `customerToOrderRatio` = 客户→订单转化率（默认 1）
- `daysPerMonth` = 每月营业天数（默认 30）

### 2.2 模式 A：已知日营业额

1. `dailyRevenue` = 用户输入的日营业额
2. `dailyOrders` = `dailyRevenue` ÷ `avgTicket`
3. `monthlyRevenue` = `dailyRevenue` × `daysPerMonth`
4. `monthlyNetProfit` = `monthlyRevenue` × `grossMargin` − `monthlyFixedCost`
5. `turnoverRate` = `dailyOrders` ÷ `seats`（`seats` > 0 时）

### 2.3 模式 B：已知月净利润

1. `monthlyNetProfit` = 用户输入的月净利润
2. `monthlyRevenue` = (`monthlyNetProfit` + `monthlyFixedCost`) ÷ `grossMargin`
3. `dailyRevenue` = `monthlyRevenue` ÷ `daysPerMonth`
4. `dailyOrders` = `dailyRevenue` ÷ `avgTicket`
5. `turnoverRate` = `dailyOrders` ÷ `seats`（`seats` > 0 时）

### 2.4 模式 C：已知日均客户数

1. `dailyCustomers` = 用户输入的日均客户数
2. `dailyOrders` = `dailyCustomers` × `customerToOrderRatio`
3. `dailyRevenue` = `dailyOrders` × `avgTicket`
4. `monthlyRevenue` = `dailyRevenue` × `daysPerMonth`
5. `monthlyNetProfit` = `monthlyRevenue` × `grossMargin` − `monthlyFixedCost`
6. `turnoverRate` = `dailyOrders` ÷ `seats`（`seats` > 0 时）

### 2.5 特殊值处理

- 当 `avgTicket` 为 0 时，无法计算日均单数，结果显示「—」。
- 当 `grossMargin` 为 0 时，月净利润模式无法反推月营业额，结果显示「—」。
- 当 `monthlyNetProfit` 模式计算出的 `monthlyRevenue` 为负数时，提示「估算参数可能不合理」。
- 当 `seats` 为 0 或未填时，不显示翻台率。

## 3. 页面结构与交互

### 3.1 总体布局

采用与现有「餐饮盈利计算器」一致的左右布局：

- **左侧输入面板**：模式选择、调研数据输入、估算参数输入、操作按钮。
- **右侧结果面板**：核心结果卡片、详细结果卡片、下载按钮。

### 3.2 左侧输入面板

从上到下的顺序：

1. **模式选择区**
   - 标签：日营业额 / 月净利润 / 日均客户数
   - 单选，选中后下方对应输入框高亮可填。

2. **调研数据输入区**
   - 根据选中模式显示对应的输入框和单位。
   - 未选中模式对应的输入框置灰或隐藏。

3. **估算参数区**
   - 平均客单价
   - 毛利率
   - 月固定成本 / 年固定成本（二选一，带自动换算）
   - 座位数（选填）
   - 客户→订单转化率（默认 100%，选填）
   - 每月营业天数（默认 30，选填）

4. **操作按钮区**
   - 加载示例
   - 清空

### 3.3 右侧结果面板

1. **核心结果卡片**
   - 大号展示「日均单数」
   - 次行展示「日营业额」「月营业额」「月净利润」
   - 如有座位数，展示「翻台率」

2. **参数回显卡片**
   - 显示当前使用的客单价、毛利率、固定成本、转化率，方便用户核对。

3. **下载结果图片按钮**
   - 生成包含所有结果和生成时间的图片。

### 3.4 底部导航

移动端沿用现有吸底导航：
- 录入数据
- 核心结果
- 参数说明

## 4. 示例场景

### 示例 1：问到日营业额

- 模式：日营业额
- 日营业额：2,000 元
- 平均客单价：20 元
- 毛利率：60%
- 月固定成本：15,000 元
- 座位数：24
- 每月营业天数：30

**结果**：
- 日均单数：100 单
- 日营业额：2,000 元
- 月营业额：60,000 元
- 月净利润：21,000 元
- 翻台率：4.17

### 示例 2：问到月净利润

- 模式：月净利润
- 月净利润：8,000 元
- 平均客单价：25 元
- 毛利率：55%
- 月固定成本：18,000 元
- 座位数：30

**结果**：
- 月营业额：(8,000 + 18,000) ÷ 0.55 ≈ 47,273 元
- 日营业额：47,273 ÷ 30 ≈ 1,576 元
- 日均单数：1,576 ÷ 25 ≈ 63 单
- 翻台率：63 ÷ 30 ≈ 2.1

### 示例 3：数到日均客户数

- 模式：日均客户数
- 日均客户数：80 人
- 客户→订单转化率：100%
- 平均客单价：18 元
- 毛利率：50%
- 月固定成本：12,000 元

**结果**：
- 日均单数：80 单
- 日营业额：1,440 元
- 月营业额：43,200 元
- 月净利润：9,600 元

## 5. 边界情况与提示文案

| 场景 | 处理方式 |
|---|---|
| 平均客单价为 0 | 日均单数显示「—」，提示「请填写平均客单价」 |
| 毛利率为 0 | 月净利润模式无法反推，显示「—」，提示「请填写毛利率」 |
| 月净利润为负且无法覆盖固定成本 | 结果显示为负数或「无法回本」，提示「按此利润估算，店铺可能处于亏损状态」 |
| 反推出的日均单数过大或过小 | 给出轻提示，例如「日均单数偏高，请核对客单价是否过低」 |
| 未填写座位数 | 正常显示其他结果，翻台率隐藏 |
| 年固定成本与月固定成本同时填写 | 以最后修改项为准，另一项自动同步换算 |
