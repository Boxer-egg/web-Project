## 二、项目要达成的目标

### 2.1 核心功能目标

| 功能 | 目标描述 | 优先级 |
|------|---------|--------|
| 顺序练习 | 用户按题库顺序逐题练习，每选完一题立即显示对错和解析，手动进入下一题 | P0 |
| 随机抽题 | 从题库中随机抽取 N 题（默认 50 题）进行练习 | P0 |
| 模拟考试 | 随机抽取 100 题，限时 45 分钟，90 分及格，到时间自动交卷 | P0 |
| 错题本 | 自动记录答错的题目，支持反复练习，支持手动移除已掌握题目 | P0 |
| 答题解析 | 每道题显示正确答案和解析说明 | P0 |
| 本地存储 | 错题、历史记录通过 LocalStorage 持久化 | P0 |
| 完全离线 | 题库 JSON 静态内嵌，不依赖外部网络 | P0 |
| 移动端适配 | 界面在手机浏览器上可用、易用 | P0 |

### 2.2 题库数据目标

| 目标 | 描述 | 优先级 |
|------|------|--------|
| 完整题库 | 科目一真实题库（约 1000+ 题），覆盖单选、判断、多选 | P1 |
| 科目四题库 | 新增科目四安全文明驾驶题库 | P1 |
| 多驾照类型 | 支持 C1/C2/A1/A2/B1/B2 等车型配置化 | P2 |
| 图片题 | 真实交通标志、标线、信号灯、交警手势等图片 | P1 |
| 数据来源 | 支持聚合数据 API 接入，或提供爬虫脚本从 jsyks.com 获取 | P1 |

### 2.3 数据格式目标

每道题统一为以下 JSON 结构：

```json
{
  "id": "c1-001",
  "type": "single",
  "question": "题干文本",
  "options": ["选项A", "选项B", "选项C", "选项D"],
  "answer": [1],
  "explain": "解析说明",
  "picture": "images/sign.png",
  "chapter": "章节分类"
}
```

- `type`：`single`（单选）、`multiple`（多选）、`truefalse`（判断）
- `answer`：数组，正确答案选项的索引
- `picture`：可选，图片路径或 URL
- `chapter`：题目章节，用于分类统计

### 2.4 用户体验目标

1. **即时反馈**：选择单选/判断答案后，立即显示对错、正确答案、解析。
2. **多选确认**：多选题需用户选择多个选项后点击"确认答案"再显示结果。
3. **手动翻页**：答题后用户主动点击"下一题"，便于消化吸收解析。
4. **进度可见**：顶部显示当前题号、总题数、倒计时、进度条。
5. **题号导航**：底部题号网格，快速跳转、已答题目有视觉标记。
6. **考试结果清晰**：交卷后显示总分、对错数量、及格状态、错题回顾。
7. **历史可追溯**：保存每次练习/考试的分数和用时。

### 2.5 技术架构目标

| 目标 | 描述 |
|------|------|
| 单文件组件 | 所有逻辑集中在一个 Vue 文件，与现有工具风格一致 |
| 静态资源 | 题库 JSON 和图片放在 `public/` 目录，构建后随站点分发 |
| LocalStorage | 错题本、历史记录使用 `@vueuse/core` 的 `useStorage` |
| 无后端依赖 | 纯前端实现，Cloudflare Pages 静态部署 |
| 可扩展性 | 后续接入真实题库时，只需替换 JSON 文件，无需改代码 |

### 2.6 AI 调用目标

页面支持通过 URL 参数启动指定模式：

```
/tools/driving-license-quiz?mode=exam&auto=1
/tools/driving-license-quiz?mode=random&auto=1
/tools/driving-license-quiz?mode=wrong&auto=1
```

便于 AI Agent 或用户通过链接直接进入对应模式。
