# 时间戳转换工具

## 功能概述
在 Unix 时间戳（秒/毫秒）和人类可读日期格式之间进行转换，支持多种格式输出。

## 输入
1. 时间戳输入框：输入 10 位（秒）或 13 位（毫秒）数字
2. 日期输入框：选择或输入日期时间，如 `2026-06-10 21:30:00`
3. **现在**按钮：自动填入当前时间

## 操作按钮
1. **时间戳 → 日期** — 将输入的时间戳转为日期字符串
2. **日期 → 时间戳** — 将输入的日期转为秒级和毫秒级时间戳
3. **复制结果** — 复制输出内容
4. **清空** — 清空所有输入
5. **加载示例** — 填入示例时间戳

## 输出
- 转换后的日期/时间戳
- 多种格式展示：
  - ISO 格式：`2026-06-10T21:30:00.000Z`
  - 本地格式：`2026-06-10 21:30:00`
  - 友好格式：`2026年6月10日 21:30:00 星期三`
- 距离现在：如 "3 天前"、"2 小时后"

```
+------------------+------------------+
|   时间戳输入      |   日期时间输出    |
|   [1234567890]   |   ISO: ...       |

|                  |   友好: ...      |
|   [时间戳→日期]  |   距离现在: ...  |
|   [现在]          |                  |

```

## 功能细节
- 自动识别输入是秒级还是毫秒级时间戳
- 日期选择器支持原生 datetime-local 或自定义组件
- 实时显示距离当前时间的相对时间
- 输出支持一键复制任意格式

## 状态流转
```
用户进入页面
    │
    ├── [现在] ──→ 自动填入当前时间戳和日期
    │
    ├── [加载示例] ──→ 填入示例时间戳
    │
    ├── 时间戳 → 日期 流程
    │   │
    │   ├── 用户输入数字 ──→ 自动识别秒/毫秒
    │   │   ├── 10 位数字 ──→ 标记为 "秒级"
    │   │   └── 13 位数字 ──→ 标记为 "毫秒级"
    │   │
    │   ├── 点击 [时间戳→日期]
    │   │   ├── 输入合法 ──→ 展示多种格式结果
    │   │   └── 输入非法（非数字/过大/过小）──→ 显示错误
    │   │
    │   └── 结果展示 ──→ 每种格式旁有 [复制] 按钮

    └── 日期 → 时间戳 流程

        ├── 用户选择/输入日期
        │
        ├── 点击 [日期→时间戳]
        │   └── 展示秒级和毫秒级两个结果
        │
        └── 结果旁有 [复制] 按钮
```

## 错误处理
| 场景 | 处理方式 |
|:---|:---|
| 时间戳为空 | 提示 "请输入时间戳" |
| 时间戳为非数字 | 提示 "请输入纯数字" |
| 时间戳超出有效范围（如负数或 >Year 3000） | 提示 "时间戳超出有效范围" |
| 日期输入格式不正确 | 提示 "日期格式不正确"，日期选择器可规避此问题 |
| 复制失败 | 提示手动复制 |

## 边界情况
- 输入 `0`：显示 Unix 纪元时间 `1970-01-01 08:00:00`
- 输入带小数的时间戳（如 `1234567890.123`）：截断小数部分处理
- 输入 10 位但数值过大（如 `9999999999`）：按秒级解析，可能超出范围
- 输入 13 位但数值过小（如 `1000000000000`）：按毫秒级解析
- 自动识别逻辑：
  - 10 位且数值在合理范围内（>0 且 <Date.now()/1000 + 1年）→ 秒级
  - 13 位且数值在合理范围内 → 毫秒级
  - 其他位数 → 提示 "请输入 10 位（秒）或 13 位（毫秒）时间戳"
- 相对时间每秒自动更新（如 "5 秒前"）
- 日期选择器使用本地时区，输出同时展示本地时间和 UTC 时间

## 本地存储策略
- 保存最近一次输入的时间戳或日期
- 保存用户偏好的展示格式（可选）

## 响应式适配
- 桌面端：左右分栏，时间戳在左，日期在右
- 移动端：上下布局，每个转换方向独立卡片
- 日期选择器在移动端使用原生组件，确保体验一致
