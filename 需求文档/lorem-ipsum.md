# Lorem Ipsum 生成器

## 功能概述
生成用于占位和排版测试的 Lorem Ipsum 假文，支持自定义段落数、每段句数、是否以中文假文输出，以及 HTML 标签包裹。

## 输入/配置
1. **段落数**：1 ~ 50
2. **每段句数**：1 ~ 20
3. **输出格式**：
   - 纯文本（段落间空行分隔）
   - HTML（`&lt;p&gt;` 标签包裹）
   - 单行（所有段落合并为一行，用空格分隔）
4. **语言**：
   - 拉丁语（标准 Lorem Ipsum）
   - 中文（基于常见中文字符的随机组合，有语义感的假文）
5. **起始文本**：是否以 "Lorem ipsum dolor sit amet..." 开头（拉丁语模式）

## 操作按钮
1. **生成** — 根据配置生成假文
2. **复制** — 复制全部结果到剪贴板
3. **导出 TXT** — 下载为 .txt 文件
4. **清空** — 清空结果

## 输出
- 文本输出框：展示生成的假文
- 统计信息：总段落数、总句数、总字符数

```

    │   ├── 拖动段落/句数滑块 ──→ 实时显示数值
    │   ├── 切换格式/语言 ──→ 如有结果，实时重新生成
```

## 边界情况
- 段落数为 1：不显示段落间空行
- 每段句数为 1：每段只有一句话
- 中文模式下标准开头不可用：自动取消勾选，提示 "中文模式不支持标准开头"
- 中文模式生成的文本：使用常见中文字符随机组合，尽量模拟自然语句长度分布（短句为主，偶尔长句）
- HTML 格式时，单行模式不可用：自动切换为纯文本
- 极大配置（50 段 × 20 句）：生成时间可能较长，显示 "生成中..."
- 生成结果超过 10000 字符：文本框显示 "内容较长，已自动滚动"

## 错误处理（异常）
| 场景 | 处理方式 |
|:---|:---|
| 段落数或句数超出范围 | 自动钳制到有效范围 |
| 生成异常 | 提示 "生成失败"，提供默认文本 |
| 复制失败 | 提示手动复制 |
| 导出失败 | 提示 "导出失败"，提供复制作为备选 |

## 本地存储策略
- 保存段落数、每段句数、格式、语言配置
- 不保存生成的内容（假文每次生成应不同）

## 响应式适配
- 桌面端：左右分栏，配置在左，结果在右
- 移动端：上下分栏，结果区可滚动
- 滑块在移动端增大触摸区域

## 技术备注
- 拉丁语词库：包含约 100 个常见 Lorem Ipsum 词汇
- 中文词库：包含约 200 个常见中文词汇/短语
- 使用 crypto.getRandomValues 或 Math.random 随机选择词汇
