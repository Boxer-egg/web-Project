# JWT 解码器

## 功能概述
解析 JWT（JSON Web Token）字符串，将 Base64Url 编码的 Header 和 Payload 解码为可读的 JSON 格式，并验证签名部分的基本格式。

## 输入
- 单行或多行文本输入框（textarea），粘贴 JWT Token
- 支持标准 JWT 格式：`header.payload.signature`

## 操作按钮
1. **解析** — 将输入的 JWT 解码为 JSON
2. **复制 Header** — 复制解码后的 Header JSON
3. **复制 Payload** — 复制解码后的 Payload JSON
4. **复制完整结果** — 复制 Header + Payload 的完整解析结果
5. **清空** — 清空输入和输出
6. **加载示例** — 填入一个有效的示例 JWT

## 输出
- **Header 区域**：解码后的 JSON，可折叠
  - 显示原始 Base64Url 字符串
  - 显示解码后的 JSON（格式化展示）
- **Payload 区域**：解码后的 JSON，可折叠
  - 显示原始 Base64Url 字符串
  - 显示解码后的 JSON（格式化展示）
  - 对常见字段（exp, iat, nbf）自动转换为可读日期
- **Signature 区域**：显示原始签名字符串（不可解码，仅展示）
- **过期状态**：如果 token 包含 exp 字段，显示 "已过期" / "未过期" / "即将过期（24小时内）"

## 界面布局
```
+------------------+------------------+
|   输入区域        |   解析结果        |
|   (JWT Token)    |                  |
|                  |   [Header] ▼     |
|   [解析]          |   { "alg":... }  |
|   [清空]          |                  |
|   [加载示例]      |   [Payload] ▼    |
|                  |   { "sub":... }  |
|                  |   exp: 2024...   |
|                  |                  |
|                  |   [Signature] ▼  |
|                  |   (原始字符串)    |
|                  |                  |
|                  |   [复制Header]   |
|                  |   [复制Payload]  |
+------------------+------------------+
```

## 状态流转（逻辑/交互）
```
用户进入页面
    │
    ├── [加载示例] ──→ 填入示例 JWT ──→ 自动触发解析
    │
    └── 用户粘贴 JWT
        │
        ├── 输入过程中实时检测格式（防抖 300ms）
        │   ├── 格式正确（两个点号分隔三部分）──→ 边框变绿提示
        │   └── 格式不正确 ──→ 显示 "请输入有效的 JWT 格式（header.payload.signature）"
        │
        ├── 点击 [解析]
        │   ├── 解码成功 ──→ 展示 Header/Payload/Signature
        │   │   └── 自动解析 exp/iat/nbf 字段为日期
        │   └── 解码失败 ──→ 显示具体错误
        │
        └── 用户点击复制按钮 ──→ 复制对应内容到剪贴板
```

## 边界情况
- 输入只有 Header.Payload（缺少 Signature）：正常解析前两部分，Signature 区域显示 "无签名"
- 输入包含多个 JWT（多行）：默认解析第一行，或提示 "检测到多个 Token，仅解析第一个"
- Header 或 Payload 不是合法 JSON：显示解码后的原始字符串，提示 "该部分不是标准 JSON"
- JWT 中包含中文字符（通过 Unicode 转义）：正确解码并显示中文
- exp/iat/nbf 值为字符串而非数字：尝试解析，失败则原样显示
- 输入带有 "Bearer " 前缀：自动去除前缀后解析
- 输入包含换行或空格：自动去除后解析

## 错误处理（异常）
| 场景 | 处理方式 |
|:---|:---|
| 输入为空时点击解析 | 提示 "请输入 JWT Token" |
| 格式不正确（缺少点号或部分为空） | 提示 "JWT 格式错误：应包含 header.payload.signature 三部分" |
| Base64Url 解码失败（含非法字符） | 提示 "解码失败：第 X 部分包含非法字符" |
| JSON 解析失败 | 提示 "该部分解码后不是有效的 JSON"，仍显示原始解码内容 |
| 复制失败 | 提示 "复制失败，请手动复制" |

## 本地存储策略
- 保存最后一次输入的 JWT（注意：JWT 可能包含敏感信息，仅保存在本地浏览器）
- 保存各折叠区域的展开/折叠状态

## 响应式适配
- 桌面端：左右分栏，输入在左，解析结果在右
- 移动端：上下分栏，输入在上，结果在下可折叠卡片形式展示
