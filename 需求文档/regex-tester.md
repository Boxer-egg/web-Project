# 正则表达式测试工具

## 功能概述
提供正则表达式的实时匹配、替换和分组提取功能，帮助开发者快速验证正则逻辑。

## 输入
1. 正则表达式输入框：输入正则，如 `\d{3}-\d{4}`
2. 标志位选择：复选框 g（全局）、i（忽略大小写）、m（多行）
3. 测试文本输入框（textarea）：输入待匹配的文本
4. 替换文本输入框（可选）：输入替换后的内容

## 操作按钮
1. **匹配测试** — 高亮显示所有匹配结果
2. **替换测试** — 显示替换后的文本
3. **提取分组** — 列出所有捕获组的内容
4. **复制结果** — 复制匹配结果或替换结果
5. **清空** — 清空所有输入
6. **加载示例** — 填入示例正则和测试文本
7. **常用正则库** — 下拉选择常用正则（手机号、邮箱、身份证号等）

## 输出
- 匹配结果区：高亮显示原文本中的匹配部分
- 替换结果区：展示替换后的文本
- 分组提取区：表格展示每个捕获组
- 匹配统计：匹配次数、位置

## 界面布局
```
+------------------+------------------+
| 正则输入: [      ] | 标志: [g] [i] [m]|
| 测试文本:         | 匹配结果高亮显示  |
| [               ] |                  |
| 替换文本: [     ] | [提取分组表]      |
| [匹配] [替换]     | [复制结果]        |
| [常用正则库▼]     | 匹配数: 3        |
| [清空] [示例]     |                  |
+------------------+------------------+
```

## 功能细节
- 实时匹配：输入时自动高亮匹配结果（无需点击按钮）
- 语法错误提示：正则不合法时实时显示错误
- 常用正则预设：手机号、邮箱、URL、IP、身份证号、日期等
- 匹配结果用不同颜色区分不同捕获组

## 状态流转
```
用户进入页面
    │
    ├── [加载示例] ──→ 填入示例正则和测试文本
    │
    └── 用户操作
        │
        ├── 修改正则表达式（防抖 200ms）
        │   ├── 正则不合法 ──→ 实时显示红色错误提示
        │   └── 正则合法 ──→ 自动执行匹配，高亮结果
        │
        ├── 修改测试文本 ──→ 实时重新匹配
        │
        ├── 切换标志位（g/i/m）──→ 实时重新匹配
        │
        ├── 选择 [常用正则库]
        │   └── 从下拉列表选择 ──→ 自动填入正则和说明
        │
        ├── 点击 [替换测试]
        │   └── 需要替换文本框有内容 ──→ 展示替换结果
        │
        └── 点击 [提取分组]
            └── 展示所有捕获组的表格
```

## 错误处理
| 场景 | 处理方式 |
|:---|:---|
| 正则不合法 | 输入框边框变红，下方显示具体错误，如 "未闭合的括号" |
| 测试文本为空 | 匹配区显示 "请输入测试文本"，不报错 |
| 正则为空 | 匹配区清空，等待输入 |
| 替换文本引用不存在的分组（如 `$9`） | 按原样输出 `$9`，不报错 |
| 无限循环正则（如 `(a+)+` 匹配长文本） | 设置超时 1 秒，超时后提示 "正则匹配超时，请简化表达式" |

## 边界情况
- 正则匹配 0 次：显示 "未匹配到结果"
- 全局模式（g）下替换：替换所有匹配
- 非全局模式替换：仅替换第一个匹配
- 测试文本极长（>10万字符）：提示 "文本过长可能影响性能"，但仍可执行
- 匹配结果包含换行：正常显示，保留换行
- 捕获组嵌套：表格中按从左到右顺序列出所有组
- 命名捕获组（如 `(?<name>\w+)`）：表格中显示组名

## 本地存储策略
- 保存用户输入的正则表达式（不包含 `/` 包裹符）
- 保存测试文本
- 保存标志位勾选状态
- 保存常用正则库的最近使用项（可选）

## 响应式适配
- 桌面端：左右分栏，正则和标志位在上，测试文本在左，结果在右
- 移动端：上下布局，正则输入在上，测试文本在中，匹配结果在下
- 匹配高亮在移动端缩小字号以适应屏幕
