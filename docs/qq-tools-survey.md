### 本期实现需求详述（8 个）

以下 8 个工具为本期要补全的前端页面，全部可在浏览器本地完成，无需后端服务。

#### 1. 计算器（Calculator）

- **功能描述**：标准科学计算器，支持按钮点击与键盘输入，可计算四则运算、括号、百分号、幂运算、取余、正负号切换，保留历史记录。
- **输入**：用户输入的数学表达式字符串，例如 `1 + 2 * (3 - 4) / 5 ^ 2`。
- **输出**：计算结果（数字）或错误提示（如括号不匹配、非法字符）。
- **页面参数**：
  - `expr`：初始表达式（可选），例如 `?expr=2*3.14*5`。
- **使用示例**：
  - 输入 `1+2*3` → 输出 `7`
  - 输入 `2^10` → 输出 `1024`
  - 输入 `(1+2` → 提示 `表达式不完整`
- **纯前端可行性**：完全可行。使用自定义表达式解析器或安全的 `new Function` 子集即可在浏览器本地计算，不依赖任何后端。

#### 2. 随机数生成器（Random Generator）

- **功能描述**：生成随机整数、浮点数、随机字符串、UUID、随机颜色。支持指定范围、生成数量、是否唯一、分隔符。
- **输入**：类型、最小值、最大值、数量、唯一性开关、字符串长度等配置。
- **输出**：单个值或按行/逗号分隔的结果列表。
- **页面参数**：
  - `type`：`int` / `float` / `string` / `uuid` / `color`
  - `min` / `max`：数值范围
  - `count`：生成数量
  - `unique`：是否去重（`1` 为是）
  - `length`：随机字符串长度
  - `prefix` / `suffix`：前后缀（可选）
- **使用示例**：
  - `?type=int&min=1&max=100&count=5` → `[23, 45, 67, 12, 88]`
  - `?type=string&length=8&count=3` → `aB3dE9fG, Hj2kL4mN, Pq5rS6tU`
  - `?type=uuid&count=2` → 两条 UUID v4
- **纯前端可行性**：完全可行。使用 `crypto.getRandomValues` 提供密码学安全随机数，所有生成逻辑在本地完成。

#### 3. YAML/JSON 互相转换（YamlJsonConverter）

- **功能描述**：在 YAML 与 JSON 之间双向转换，粘贴后实时输出结果，支持格式化/压缩，并高亮语法错误位置。
- **输入**：YAML 文本或 JSON 文本。
- **输出**：转换后的对应格式文本。
- **页面参数**：
  - `input`：要转换的文本
  - `direction`：`yaml2json` 或 `json2yaml`
  - `compact`：是否压缩输出（`1` 为是）
- **使用示例**：
  - `name: Alice\nage: 30`（YAML）→ `{"name":"Alice","age":30}`
  - `{"name":"Alice","age":30}`（JSON）→ YAML 格式
- **纯前端可行性**：完全可行。引入 `js-yaml` 库在浏览器解析与序列化，所有数据不离开本机。

#### 4. 数字大小写转换（NumberToChinese）

- **功能描述**：将阿拉伯数字转换为中文大写金额、中文小写数字或人民币读法。支持整数、小数、负数。
- **输入**：数字字符串或数值，例如 `1024.50`。
- **输出**：
  - 大写金额：`壹仟零贰拾肆元伍角整`
  - 中文小写：`一千零二十四点五`
  - 人民币读法：`1024.50 元`
- **页面参数**：
  - `number`：要转换的数字
  - `mode`：`upper`（大写金额） / `lower`（中文小写） / `currency`（人民币读法）
- **使用示例**：
  - `?number=1024.5&mode=upper` → `壹仟零贰拾肆元伍角`
  - `?number=-305&mode=lower` → `负三百零五`
- **纯前端可行性**：完全可行。使用汉字数字映射表和位权规则，纯本地转换。

#### 5. 手持弹幕 LED（LedMarquee）

- **功能描述**：将输入文字以全屏滚动字幕形式展示，可调节滚动速度、文字颜色、背景颜色、字号、滚动方向，支持循环播放。
- **输入**：要展示的文字与视觉配置。
- **输出**：全屏动画效果，可一键退出全屏。
- **页面参数**：
  - `text`：弹幕文字
  - `speed`：滚动速度（1-10）
  - `color`：文字颜色
  - `bg`：背景颜色
  - `size`：字号（px）
  - `direction`：`left` / `right` / `up` / `down`
- **使用示例**：
  - `?text=加油&color=%23ff0000&bg=%23000000&speed=5` → 黑底红字横向滚动“加油”
- **纯前端可行性**：完全可行。使用 CSS 动画或 `requestAnimationFrame` 实现全屏滚动，无需网络请求。

#### 6. 图片 Canvas 处理（ImageCanvasToolbox）

- **功能描述**：上传本地图片后，在浏览器中完成像素化（马赛克）、黑白化（灰度）、添加文字水印、压缩（质量/尺寸）、九宫格切图、格式转换（PNG/JPEG/WebP）。
- **输入**：用户上传的图片文件（支持点击上传、拖拽、粘贴）。
- **输出**：处理后的图片预览，可下载单张或打包下载九宫格。
- **页面参数**：图片处理属于文件输入型工具，不适合 URL 传参，因此页面不通过 query 接收文件，仅通过 UI 操作。
- **使用示例**：
  - 上传 `photo.jpg`，选择“九宫格切图” → 生成 9 张等分图片并打包下载
  - 上传 `logo.png`，选择“压缩 80%” → 下载更小体积的 PNG
- **纯前端可行性**：完全可行。HTML5 Canvas 可以直接读取 `FileReader` 得到的图片，进行像素级处理并导出为 DataURL/Blob。

#### 7. 邮编 / 车牌 / 电话区号查询（ZipPlateAreaQuery）

- **功能描述**：提供三种查询：输入邮政编码查省市、输入车牌前缀（如 `粤B`）查归属地、输入电话区号（如 `0755`）查城市。支持关键词模糊匹配。
- **输入**：查询类型与关键词。
- **输出**：匹配结果列表，包含编码/前缀、对应地区、行政归属。
- **页面参数**：
  - `type`：`zip` / `plate` / `area`
  - `q`：查询关键词
- **使用示例**：
  - `?type=plate&q=粤B` → 广东省深圳市
  - `?type=zip&q=518000` → 广东省深圳市
  - `?type=area&q=0755` → 广东深圳
- **纯前端可行性**：完全可行。全国邮编、车牌前缀、电话区号数据量可控，可打包为静态 JSON 或对象映射，本地查询。

#### 8. 垃圾分类查询（GarbageClassification）

- **功能描述**：输入常见垃圾名称，返回所属分类（可回收物、有害垃圾、厨余垃圾、其他垃圾）及投放提示。
- **输入**：物品名称关键词。
- **输出**：分类名称、颜色标识、投放说明、常见示例列表。
- **页面参数**：
  - `q`：物品名称，例如 `?q=电池`
- **使用示例**：
  - `?q=电池` → 有害垃圾（红色），提示“投放至有害垃圾桶”
  - `?q=报纸` → 可回收物（蓝色），提示“保持干燥、压平后投放”
- **纯前端可行性**：完全可行。准备一份常见垃圾与分类的映射表即可本地查询；数据量不大，可增量维护。

#### 9. 保质期计算（ShelfLifeCalculator）

- **功能描述**：根据用户输入的生产日期和保质期长度，计算过期日期、距离今天还剩多少天，以及是否已过期。支持保质期以天、月、年为单位。
- **输入**：生产日期（`YYYY-MM-DD`）、保质期数值、保质期单位。
- **输出**：
  - 过期日期（格式化与 ISO 格式）
  - 剩余天数（正数表示未过期，负数表示已过期）
  - 状态标签（新鲜/即将到期/已过期）
- **页面参数**：
  - `date`：生产日期，例如 `?date=2026-06-01`
  - `value`：保质期数值，例如 `?value=30`
  - `unit`：单位 `day` / `month` / `year`，例如 `?unit=day`
  - `auto`：是否自动计算（`1` 为是）
- **使用示例**：
  - `?date=2026-06-01&value=30&unit=day&auto=1` → 过期日期 2026-07-01，剩余 30 天
  - `?date=2025-01-01&value=1&unit=year&auto=1` → 过期日期 2026-01-01，根据当前日期显示剩余或已过期天数
- **纯前端可行性**：完全可行。所有计算基于 JavaScript `Date` 对象在浏览器本地完成，无需后端或网络请求。跨月/跨年日期通过 `setMonth` / `setFullYear` 自动处理。

#### 10. 血型遗传规律（BloodTypeInheritance）

- **功能描述**：根据父亲和母亲的 ABO 血型（可选 Rh 阴阳性），推算子女可能出现的血型及对应概率。支持单亲和双亲输入，并给出遗传学简要说明。
- **输入**：父母血型。ABO 血型为 `A`、`B`、`AB`、`O`；Rh 血型用 `+`（阳性）或 `-`（阴性）附加，如 `A+`、`O-`。若省略 Rh，默认只分析 ABO。
- **输出**：
  - 子女可能的 ABO 血型列表
  - 子女可能的 Rh 阴阳性列表（当输入包含 Rh 时）
  - 各血型的出现概率
  - 遗传说明（如“A 型与 B 型父母，子女四种血型均可能”）
- **页面参数**：
  - `parent1`：父亲血型，例如 `?parent1=A` 或 `?parent1=AB+`
  - `parent2`：母亲血型，例如 `?parent2=B` 或 `?parent2=O-`
  - `auto`：是否自动计算（`1` 为是）
- **使用示例**：
  - `?parent1=A&parent2=B&auto=1` → 子女 ABO 血型可能为 A、B、AB、O，各约 25%
  - `?parent1=AB+&parent2=O-&auto=1` → 子女 ABO 血型可能为 A 或 B；Rh 可能为阳性或阴性，各 50%
  - `?parent1=O&parent2=O&auto=1` → 子女只能为 O 型
- **纯前端可行性**：完全可行。血型遗传遵循明确的孟德尔遗传规律，可通过静态基因型组合表在浏览器本地计算，无需后端。

#### 11. 亲戚关系计算（RelationshipCalculator）

- **功能描述**：支持两种查询模式：① 输入亲属关系链，输出正确的中文称谓；② 输入称谓，反向输出常见关系链。覆盖父系、母系、夫系、妻系等常用亲属关系，结果以口语化称谓为主。
- **输入**：
  - 模式 `query`：关系链，多个关系用逗号分隔，例如 `爸爸,妈妈,哥哥`
  - 模式 `reverse`：称谓，例如 `舅公`、`堂姐`、`外甥女`
- **输出**：
  - `query` 模式：对应的标准称谓、关系解释、是否为血亲/姻亲
  - `reverse` 模式：该称谓对应的常见关系链、关系解释
- **页面参数**：
  - `chain`：关系链，例如 `?chain=爸爸,妈妈,哥哥`
  - `title`：称谓，例如 `?title=舅公`
  - `mode`：`query`（链→称谓）或 `reverse`（称谓→链），默认 `query`
  - `auto`：是否自动计算（`1` 为是）
- **使用示例**：
  - `?chain=爸爸,妈妈,哥哥&mode=query&auto=1` → 称谓为「舅父」（舅舅）
  - `?chain=爸爸,弟弟&mode=query&auto=1` → 称谓为「叔叔」
  - `?title=舅公&mode=reverse&auto=1` → 常见关系链：「爸爸的妈妈的哥哥」或「妈妈的哥哥的爸爸」（同辈不同支）
- **纯前端可行性**：可行。常见亲属称谓可通过静态映射表覆盖；较复杂的多层关系链可基于状态机或有限关系节点图在本地推导。为保证准确性，初期可限定关系链长度（如最多 6 层）并优先覆盖高频称谓。

#### 12. 文字转拼音（PinyinConverter）

- **功能描述**：将输入的中文文本转换为拼音。支持带声调、不带声调、首字母三种输出格式；支持保留非中文字符原样输出或过滤；支持按词分词后输出整词拼音（如"中国"→"zhōng guó"）。
- **输入**：任意中/英/数字混合文本。
- **输出**：转换后的拼音文本，以及转换统计（中文字符数、非中文字符数）。
- **页面参数**：
  - `text`：要转换的文本，例如 `?text=你好世界`
  - `tone`：声调模式，`tone`（带声调，默认）、`none`（无声调）、`first`（首字母）
  - `segment`：是否在多音字分词后按词输出，`1` 为是
  - `preserve`：是否保留非中文字符，`1` 为保留（默认）
- **使用示例**：
  - `?text=你好世界&tone=none` → `ni hao shi jie`
  - `?text=中华人民共和国&tone=first` → `zhrmghg`
  - `?text=重庆&tone=tone&segment=1` → `chóng qìng`
- **纯前端可行性**：可行。引入 `pinyin-pro` 等开源库在浏览器本地完成分词与拼音映射；数据打包后体积较大，可通过异步 chunk 加载。

#### 13. 汉字标准发音 / 偏旁（HanziInfo）

- **功能描述**：输入单个汉字，查询其拼音、声调、笔画数、部首、偏旁、结构（左右/上下/独体等）以及基本释义。用于学习汉字标准读音和字形信息。
- **输入**：单个汉字字符。
- **输出**：
  - 拼音与声调
  - 笔画数
  - 部首与偏旁
  - 结构类型
  - 基本释义（多条）
- **页面参数**：
  - `char`：要查询的汉字，例如 `?char=鑫`
- **使用示例**：
  - `?char=明` → 拼音 míng，部首日，偏旁月，结构左右，释义"明亮、清楚"
  - `?char=淼` → 拼音 miǎo，部首水，结构品字形，释义"水势浩大"
- **纯前端可行性**：可行。使用 `hanzi-writer` 或 `@pengshaonew/hanzi` 等离线汉字数据包；笔画、部首、释义可来自本地 JSON。

#### 14. 火星文翻译器（MartianText）

- **功能描述**：在普通中文/英文与火星文之间互相转换。提供一组字符替换映射表（如"的"→"ㄖ"、"我"→"莪"、"你"→"伱"等），用户可自定义部分替换规则；支持一键复制。
- **输入**：普通文本或火星文文本。
- **输出**：转换后的文本。
- **页面参数**：
  - `text`：要转换的文本
  - `direction`：`toMartian`（转火星文，默认）或 `toNormal`（转回普通文）
- **使用示例**：
  - `?text=我爱你&direction=toMartian` → `莪嗳伱`
  - `?text=莪嗳伱&direction=toNormal` → `我爱你`
- **纯前端可行性**：完全可行。维护一个中文字符到火星文字符的双向映射表即可在本地完成转换。

#### 15. 开发语言输出 hello world（HelloWorldSnippets）

- **功能描述**：列出常见编程语言的 Hello World 代码片段，用户选择语言后展示对应代码、运行说明和语言简介。支持一键复制代码。
- **输入**：语言名称或别名。
- **输出**：对应语言的 Hello World 代码、简要说明。
- **页面参数**：
  - `lang`：语言名称或别名，例如 `?lang=python`
- **使用示例**：
  - `?lang=javascript` → `console.log('Hello, World!');`
  - `?lang=c` → `#include <stdio.h>\nint main() { printf("Hello, World!\\n"); return 0; }`
  - `?lang=rust` → `fn main() { println!("Hello, World!"); }`
- **纯前端可行性**：完全可行。所有代码片段为静态文本，本地维护一个语言映射对象即可。

#### 16. 文本颜艺 / 文字隐写（TextArtAndSteganography）

- **功能描述**：提供两类功能：
  1. **颜艺/颜文字**：将普通文字用零宽字符、特殊 Unicode 符号或颜文字风格进行装饰（如把"你好"转换成"(｡･ω･｡)ﾉ♡ 你好 ♡(｡･ω･｡)"）。
  2. **文字隐写**：使用零宽空格（U+200B）、零宽连接符（U+200D）等不可见字符，在公开文本中隐藏一段秘密文本；并提供提取功能。
- **输入**：
  - 颜艺模式：公开文本、装饰模板
  - 隐写模式：载体文本（carrier）与要隐藏的秘密文本（secret）
- **输出**：
  - 颜艺模式：装饰后的文本
  - 隐写模式：携带隐藏信息的文本；提取模式则输出隐藏的秘密文本
- **页面参数**：
  - `mode`：`decorate`（颜艺装饰）、`hide`（隐写隐藏）、`extract`（隐写提取）
  - `text`：公开文本/载体文本
  - `secret`：要隐藏的秘密文本（仅 `hide` 模式）
  - `hidden`：携带隐藏信息的文本（仅 `extract` 模式）
- **使用示例**：
  - `?mode=decorate&text=你好` → 返回装饰后文本
  - `?mode=hide&text=这是一段公开文字&secret=秘密` → 在"公开文字"中隐藏"秘密"
  - `?mode=extract&hidden=<携带隐藏信息的文本>` → 提取出 `秘密`
- **纯前端可行性**：完全可行。颜艺基于字符串模板替换；隐写基于零宽字符的二进制编码/解码，全部在浏览器本地完成。

## 三、需要后端、AI/ML 模型或外部 API，不适合纯前端的

- PDF 转 Word / Excel / PPT / HTML / 图片 / 拆分 / 合并 / 加水印 / 签名 / 加解密 / 瘦身 等
- 证件照生成、照片修复、去手写、去摩尔纹、文档扭曲恢复
- 图片转 Excel / 身份证识别 / 银行卡识别 / OCR（印刷体/手写体/广告体/营业执照/名片/护照 等）
- 人脸年龄/性别/卡通画/二次元/油画/童话脸/乔丹风格/国漫水彩/人像分割/多人卡通画
- 文本转语音（TTS）
- 翻译（需要翻译 API）
- 快递查询、医院推荐（需要实时数据接口）
- 视频转 GIF / GIF 分解合成 / 在线录屏后处理
- 二维码扫描、文档扫描（需要摄像头+OCR）
- 合同验签、合同对比、文件安全检测、手机安装包检测

## 四、结论

- **纯前端可快速补齐**的：YAML/JSON 转换、计算器、随机数、数字大小写、手持弹幕、图片 Canvas 处理（像素化/黑白/水印/压缩/九宫格）、各类静态查询表（邮编、车牌、区号、朝代、首都、元素周期表、食物热量、成语/歇后语等）。
- **需要后端能力**的：PDF 处理、OCR、AI 图像滤镜、TTS、翻译、快递/医院等实时数据。
