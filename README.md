## 特点

- **免费、免登录**：打开即用，不需要注册账号。
- **隐私友好**：工具数据默认在浏览器本地处理；除你主动使用云同步或发送反馈外，数据不会上传。
- **手机可用**：电脑、平板、手机浏览器都能正常使用。
- **分享方便**：部分工具支持生成带当前参数的分享链接，发给别人即可复现结果。
