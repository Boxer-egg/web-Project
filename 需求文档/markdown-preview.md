# Markdown 预览工具

## 功能概述
实时将 Markdown 文本渲染为 HTML 预览，支持导出 HTML 文件，方便编写和检查 Markdown 文档。

## 输入
- 左侧多行文本输入框（textarea）：输入 Markdown 原文
- 支持常见的 Markdown 语法：标题、列表、代码块、表格、链接、图片等

## 操作按钮
1. **加载示例** — 填入包含各种语法的示例 Markdown
2. **清空** — 清空输入
3. **复制 HTML** — 复制渲染后的 HTML 源码
4. **导出 HTML** — 下载当前渲染结果为 .html 文件
5. **分屏/全屏切换** — 切换编辑器布局模式

## 输出
- 右侧实时预览区：渲染后的 HTML 内容
- 与输入同步，输入时即时更新（无需点击按钮）

## 界面布局
```
+------------------+------------------+
|   Markdown 编辑   |   HTML 预览      |
|                  |                  |
|   # 标题          |   渲染后的标题    |
|   - 列表项        |   • 列表项        |
|   `代码`          |   代码块样式      |
|                  |                  |
|   [加载示例]      |   [复制 HTML]    |
|   [清空]          |   [导出 HTML]    |
|   [全屏切换]      |                  |
+------------------+------------------+
```

## 功能细节
- 实时预览：输入框内容变化时，预览区 300ms 内更新（防抖）
- 支持 GitHub Flavored Markdown（GFM）语法
- 代码块支持语法高亮
- 表格渲染为 HTML 表格
- 导出的 HTML 包含基础样式，可直接打开查看
- 分屏模式下左右各 50%；全屏编辑模式下隐藏预览，全屏预览模式下隐藏编辑

## 状态流转
```
用户进入页面
    │
    ├── 默认显示说明文档（如本工具支持的 Markdown 语法说明）
    │
    ├── [加载示例] ──→ 填入包含标题、列表、代码块、表格的示例
    │
    ├── 用户输入 Markdown
    │   └── 防抖 300ms 后渲染预览
    │       ├── 渲染成功 ──→ 预览区更新
    │       └── 包含不支持的语法 ──→ 按纯文本显示，不报错
    │
    ├── 布局切换
    │   ├── 分屏模式（默认）──→ 左右各 50%
    │   ├── 编辑全屏 ──→ 编辑区 100%，预览隐藏
    │   └── 预览全屏 ──→ 预览区 100%，编辑隐藏
    │
    ├── [复制 HTML]
    │   └── 复制当前渲染后的 HTML 源码到剪贴板
    │
    └── [导出 HTML]
        └── 下载一个包含基础 CSS 样式的完整 HTML 文件
```

## 错误处理
| 场景 | 处理方式 |
|:---|:---|
| 输入为空 | 预览区显示 "开始输入 Markdown..." 或空白 |
| Markdown 语法错误（如未闭合的代码块） | 尽量容错渲染，不报错 |
| HTML 导出失败 | 提示 "导出失败"，提供复制 HTML 的备选方案 |
| 复制失败 | 提示手动复制 |

## 边界情况
- 输入超长的单行文本：自动换行，不破坏布局
- 输入大量代码块：代码区独立滚动，不影响整体页面
- 输入包含 HTML 标签（如 `<script>`）：转义显示，不执行（XSS 防护）
- 输入包含恶意链接：正常渲染，但 `target="_blank"` + `rel="noopener noreferrer"`
- 表格列数不一致：按第一行列数补齐空单元格
- 代码块未指定语言：按纯文本显示，无高亮
- 图片链接失效：显示 alt 文本，不崩溃

## 本地存储策略
- 自动保存用户输入的 Markdown 内容到 `localStorage`
- 保存当前布局模式（分屏/编辑全屏/预览全屏）
- 页面刷新后自动恢复内容和布局
- 提供 "清除内容" 按钮（与清空功能一致）

## 响应式适配
- 桌面端（≥768px）：默认左右分屏
- 移动端（<768px）：默认上下分屏，编辑在上（40%），预览在下（60%）
- 全屏编辑模式在移动端：编辑区全屏，底部悬浮切换按钮
- 代码块在移动端横向滚动，不折行
