# URL 编解码工具

## 功能概述
对 URL 字符串进行编码（encode）和解码（decode）操作，支持自动识别当前输入是编码后还是原始内容。

## 输入
- 一个多行文本输入框，输入 URL 或参数

## 操作按钮
1. **编码 (encode)** — 使用 encodeURIComponent 进行编码
2. **解码 (decode)** — 使用 decodeURIComponent 进行解码
3. **全部编码** — 对输入中所有非字母数字字符编码
4. **自动识别** — 自动判断是编码还是解码并执行对应操作
5. **复制结果** — 复制输出内容
6. **清空** — 清空输入输出
7. **加载示例** — 填入带中文和特殊字符的示例 URL

## 输出
- 一个多行文本输出框，展示编码/解码结果
- 下方显示解析后的 URL 参数表格（key-value 形式）

## 界面布局
```
+------------------+------------------+
|   输入区域        |   输出区域        |
|   (原始/编码 URL)|   (处理后结果)    |
|                  |                  |
|   [编码]          |   [复制结果]      |
|   [解码]          |                  |
|   [自动识别]      |   [参数解析表]    |
|   [清空]          |   key | value    |
|   [加载示例]      |   ----+--------  |
+------------------+------------------+
```

## 功能细节
- 默认使用 encodeURIComponent（处理中文、空格等）
- 解码失败时给出明确错误提示
- 自动解析输出中的 URL 查询参数并展示为表格
- 支持批量处理多行 URL

## 状态流转
```
用户进入页面
    │
    ▼
输入框为空
    │
    ├── [加载示例] ──→ 填入含中文和参数的示例 URL
    │
    └── 用户粘贴/输入 URL
        │
        ├── 点击 [编码]
        │   ├── 多行输入 ──→ 每行分别编码，结果每行输出
        │   └── 单行输入 ──→ 单条编码结果
        │
        ├── 点击 [解码]
        │   ├── 解码成功 ──→ 展示解码结果 + 参数解析表格
        │   └── 解码失败 ──→ 显示 "解码失败：包含非法转义序列"
        │
        └── 点击 [自动识别]
            ├── 输入含 `%` 且可解码 ──→ 执行解码
            └── 输入不含 `%` 或解码失败 ──→ 执行编码
```

## 错误处理
| 场景 | 处理方式 |
|:---|:---|
| 输入为空 | 输出框显示 "请输入 URL 内容" |
| decodeURIComponent 失败 | 精确定位错误字符，如 "%ZZ" 是无效的 |
| 解码后非合法 URL | 正常显示解码结果，不做 URL 格式校验 |
| 参数解析时 key 重复 | 表格中同一 key 显示多行 |
| 复制失败 | 提示手动复制，自动选中输出文本 |

## 边界情况
- 输入已编码的 URL：解码后还原原始字符
- 输入混合编码（部分编码部分未编码）：逐字符处理，已编码的保持不变
- 输入只有查询参数（如 `?a=1&b=2`）：正常编码/解码
- 输入包含 `#` 锚点：`encodeURIComponent` 会编码 `#`，这是符合预期的
- 参数值为空（如 `?a=&b=2`）：表格中 value 列为空
- 参数无 value（如 `?a&b=2`）：表格中 value 列显示 "(无值)"
- 多行输入：每行独立处理，结果分行展示

## 本地存储策略
- 保存最后一次输入的 URL 文本
- 保存参数解析表格的展开/折叠状态（可选）

## 响应式适配
- 桌面端：左右分栏，参数表格在输出区下方
- 移动端：上下分栏，参数表格横向滚动（防止内容被挤压）
