# 进制转换器

## 功能概述
在二进制、八进制、十进制、十六进制之间进行相互转换，支持整数和浮点数，同时提供二进制位运算相关的辅助展示。

## 输入
- 数字输入框：输入待转换的数字
- 源进制选择：2 / 8 / 10 / 16 / 36 / 62
- 目标进制选择：多选（可同时选择多个目标进制）

## 操作按钮
1. **转换** — 按源进制解析输入，转换到所有选中的目标进制
2. **交换进制** — 交换源进制和第一个目标进制
3. **复制结果** — 复制指定进制的转换结果
4. **复制全部** — 以表格形式复制所有结果
5. **清空** — 清空输入和输出
6. **加载示例** — 填入示例数字

## 输出
- 结果卡片列表：每个选中的目标进制一个卡片
  - 进制标签（二进制 / 八进制等）
  - 转换结果（可复制）
- 二进制位展示（当源或目标包含二进制时）：
  - 显示每 4 位一组的二进制分组
  - 显示对应的十六进制位

## 状态流转（逻辑/交互）
```
用户进入页面
    │
    ├── [加载示例] ──→ 填入示例数字 ──→ 自动转换
    │
    └── 用户输入数字
        │
        ├── 选择源进制（默认十进制）
        │
        ├── 选择目标进制（默认全选）
        │   └── 至少选一个，全部取消时提示
        │
        ├── 点击 [转换]
        │   ├── 输入为空 ──→ 输出空，不报错
        │   ├── 输入在源进制下不合法 ──→ 提示 "该数字不符合 X 进制格式"
        │   └── 输入合法 ──→ 展示所有目标进制结果
        │
        └── 点击 [交换]
            └── 源进制与第一个目标进制互换，重新转换
```

## 边界情况
- 输入空字符串：输出全部为空
- 输入含前缀（如 `0x7B`、`0b1010`）：自动识别前缀并切换源进制
- 输入负数：支持负数，在二进制中展示补码形式
- 输入小数：浮点数进制转换（精确度有限，提示 "浮点转换可能存在精度误差"）
- 输入极大数（>Number.MAX_SAFE_INTEGER）：提示 "数字过大，可能丢失精度"
- 输入非法字符（如二进制输入 `102`）：提示 "二进制只能包含 0 和 1"
- 36 进制和 62 进制包含字母：不区分大小写处理
- 全角数字：自动转为半角后处理

## 错误处理（异常）
| 场景 | 处理方式 |
|:---|:---|
| 输入为空 | 输出为空，不报错 |
| 源进制下数字格式错误 | 提示 "输入 'xxx' 不是有效的 X 进制数字" |
| 未选择任何目标进制 | 提示 "请至少选择一个目标进制" |
| 数字超出安全范围 | 提示 "数字过大，结果可能不精确"，仍尝试转换 |
| 复制失败 | 提示手动复制 |

## 本地存储策略
- 保存最后一次输入的数字
- 保存源进制和目标进制选择
- 保存 "自动前缀识别" 开关状态

## 响应式适配
- 桌面端：左右分栏，结果区以卡片网格展示
- 移动端：上下分栏，结果卡片 2 列或单列排列
