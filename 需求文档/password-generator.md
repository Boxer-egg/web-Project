# 随机字符串生成器

## 功能概述
根据用户自定义的规则生成随机密码或随机字符串，支持多种字符集组合。

## 输入/配置
1. 长度滑块/输入框：选择生成字符串的长度（4 ~ 128）
2. 字符集选项（复选框）：
   - 小写字母 (a-z)
   - 大写字母 (A-Z)
   - 数字 (0-9)
   - 特殊符号 (!@#$%^&*...)
   - 自定义字符集（可选输入框）
3. 数量选择：一次生成 1~10 个结果
4. 高级选项：
   - 排除易混淆字符（如 0/O, 1/l/I）
   - 确保包含至少每类字符各一个

## 操作按钮
1. **生成** — 根据配置生成随机字符串
2. **复制** — 复制选中的结果到剪贴板
3. **复制全部** — 复制所有生成结果
4. **清空** — 清空结果

## 输出
- 结果列表区：展示生成的字符串
- 每个结果旁有单独的复制按钮
- 强度指示：用颜色条显示密码强度（弱/中/强）

## 功能细节
- 使用 crypto.getRandomValues 生成真随机数（非 Math.random）
- 密码强度计算基于长度和字符集复杂度
- 生成结果可一键复制
- 支持批量生成多个结果
- 历史记录（可选）：保存最近 10 次生成结果

## 状态流转
```
用户进入页面
    │
    ├── 默认配置：长度 16，勾选小写+大写+数字
    │
    ├── 用户调整配置
    │   ├── 拖动长度滑块 ──→ 实时显示当前长度数值
    │   ├── 勾选/取消字符集 ──→ 实时更新密码强度预估
    │   │   └── 全部取消 ──→ 提示 "请至少选择一种字符集"
    │   └── 调整数量 ──→ 实时显示数量
    │
    ├── 用户点击 [生成]
    │   ├── 配置合法 ──→ 生成结果列表
    │   └── 未选任何字符集 ──→ 提示并阻止生成
    │
    ├── 用户点击单个结果旁的 [复制]
    │   └── 复制该条到剪贴板，按钮变 "已复制" 2 秒后恢复
    │
    ├── 用户点击 [复制全部]
    │   └── 所有结果以换行分隔复制到剪贴板
    │
    └── 用户点击 [清空]
        └── 清空结果列表，保留配置
```

## 错误处理
| 场景 | 处理方式 |
|:---|:---|
| 未选择任何字符集时点击生成 | 提示 "请至少选择一种字符集"，按钮置灰或点击后弹出提示 |
| 长度小于 4 | 自动钳制到 4，或提示 "最小长度为 4" |
| 长度大于 128 | 自动钳制到 128，或提示 "最大长度为 128" |
| 启用 "确保每类" 但长度小于字符集种类数 | 提示 "长度必须大于等于字符集种类数" |
| 浏览器不支持 crypto API | 降级使用 Math.random()，提示 "使用伪随机数生成" |
| 复制失败 | 提示手动复制 |

## 边界情况
- 数量为 1：只显示一个结果，不显示列表标记
- 长度为 4 且勾选所有字符集 + "确保每类"：每个字符分别来自不同字符集，剩余随机
- 自定义字符集为空：忽略该选项
- 自定义字符集只有 1 个字符：所有生成字符都是该字符
- 排除易混淆字符时选择了仅含易混淆字符的字符集：可能生成失败，提示 "可用字符不足"
- 密码强度计算规则：
  - 弱：长度 < 8，或仅单一字符集
  - 中：长度 8~11，或两种字符集
  - 强：长度 ≥12，且三种及以上字符集
- 批量生成时，确保每个结果都是独立随机，不重复（非强制，但尽量分散）

## 本地存储策略
- 保存用户配置：长度、字符集勾选、数量、高级选项
- 保存最近 5 次生成结果（可选）
- 不保存自定义字符集内容（安全考虑）

## 响应式适配
- 桌面端：左右分栏，配置区在左，结果区在右
- 移动端：上下布局，配置区在上，结果区在下
- 长度滑块在移动端增大触摸区域
- 结果列表在移动端全宽，复制按钮固定宽度
