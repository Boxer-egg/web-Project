# 文本处理工具箱

## 功能概述
提供多种常用的文本处理功能集合，包括大小写转换、去重、排序、翻转、替换等，一站式处理文本格式问题。

## 输入
- 多行文本输入框（textarea）：输入待处理的文本

## 操作按钮/功能列表

### 大小写转换
1. **转大写** — 所有字母转为大写
2. **转小写** — 所有字母转为小写
3. **首字母大写** — 每行/每个单词首字母大写
4. **大小写翻转** — 大写变小写，小写变大写

### 文本清理
5. **去重行** — 删除完全重复的行（保留第一次出现）
6. **去空行** — 删除所有空行
7. **去首尾空格** — 每行去除首尾空白字符
8. **合并空行** — 多个连续空行合并为一个

### 排序与顺序
9. **升序排序** — 按字母顺序升序排列所有行
10. **降序排序** — 按字母顺序降序排列所有行
11. **反转行序** — 整行倒序排列（第一行变最后一行）
12. **字符翻转** — 每行字符顺序颠倒

### 替换与转换
13. **查找替换** — 查找指定文本并替换（支持正则）
14. **添加行号** — 每行前添加行号（如 `1. 内容`）
15. **删除行号** — 删除每行开头的数字和点号
16. **文本转列表** — 每行转为引号包裹的列表项

### 其他
17. **统计信息** — 显示字符数、单词数、行数、字节数
18. **清空** — 清空输入和输出
19. **加载示例** — 填入示例文本

## 输出
- 多行文本输出框，展示处理后的结果
- 统计信息区：实时显示当前文本的字符数/单词数/行数/字节数

## 状态流转（逻辑/交互）
```
用户进入页面
    │
    ├── [加载示例] ──→ 填入示例文本
    │
    ├── 用户输入文本
    │   └── 实时更新统计信息（字符数/单词数/行数/字节数）
    │
    ├── 点击任意处理按钮
    │   ├── 输入为空 ──→ 输出为空，不报错
    │   └── 输入有内容 ──→ 执行对应处理逻辑
    │       ├── 处理结果与输入相同 ──→ 正常输出（如全大写文本再转大写）
        │   └── 处理结果不同 ──→ 更新输出框
    │
    ├── 连续点击不同按钮
    │   └── 每个按钮对原始输入处理（非链式处理）
    │       └── 如需链式处理，用户需手动将输出复制到输入
    │
    └── 点击 [复制结果] ──→ 复制到剪贴板
```

## 边界情况
- 输入为空：所有操作输出空字符串，统计全为 0
- 输入只有空白字符：去空行后输出空字符串
- 去重行时大小写敏感：`ABC` 和 `abc` 视为不同行
- 排序时数字 vs 字母：按字符串排序（"10" 在 "2" 前面）
- 字符翻转时多字节字符（如中文、emoji）：逐字符翻转，保持完整
- 添加行号后再次添加：行号会累加（如 `1. 1. 内容`）
- 查找替换时查找内容为空：提示 "请输入查找内容"
- 查找替换时替换内容为空：删除匹配的查找内容
- 查找替换支持正则时无效正则：提示 "正则表达式无效"
- 统计信息中 "单词数" 定义：以空白字符分隔的连续非空白字符序列
- 统计信息中 "字节数"：UTF-8 编码后的字节长度（中文 = 3 字节）

## 错误处理（异常）
| 场景 | 处理方式 |
|:---|:---|
| 输入为空时点击处理 | 输出空字符串，不报错 |
| 查找替换中查找为空 | 提示 "请输入要查找的内容" |
| 查找替换中正则无效 | 提示 "正则表达式语法错误" |
| 复制失败 | 提示手动复制 |

## 本地存储策略
- 保存最后一次输入的文本
- 保存查找/替换输入框的内容

## 响应式适配
- 桌面端：左右分栏，功能按钮区在输入区下方或侧边
- 移动端：上下分栏，功能按钮区分组展示，可横向滚动或折叠
- 统计信息在移动端固定显示在输出框上方
