# UUID 生成器

## 功能概述
批量生成 UUID（通用唯一识别码），支持 v4 版本（随机生成），提供多种格式输出（带横线、纯数字、大写等）。

## 输入/配置
1. **版本选择**：v4（随机）
2. **数量滑块**：1 ~ 100 个
3. **格式选项**：
   - 标准格式（`xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx`）
   - 无横线（`xxxxxxxxxxxx4xxxyxxxxxxxxxxxxxxx`）
   - 大写（`XXXXXXXX-XXXX-4XXX-YXXX-XXXXXXXXXXXX`）
   - 带引号（`'xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx'`）
   - 数组格式（`['uuid1', 'uuid2']`）
4. **前缀/后缀**（可选）：在每个 UUID 前后添加自定义字符串

## 操作按钮
1. **生成** — 根据配置生成 UUID 列表
2. **复制全部** — 复制所有生成的 UUID
3. **复制单个** — 每个 UUID 旁有独立复制按钮
4. **导出** — 下载为 .txt 文件
5. **清空** — 清空结果

## 输出
- 结果列表区：每行一个 UUID
- 总数统计：显示生成了多少个
- 去重检查：提示是否有重复（理论上概率极低，但作为边界检查）

## 状态流转（逻辑/交互）
```
用户进入页面
    │
    ├── 默认配置：数量 10，标准格式
    │
    ├── 用户调整配置
    │   ├── 拖动数量滑块 ──→ 实时显示当前数值
    │   ├── 切换格式 ──→ 实时更新预览（如有已生成结果）
    │   └── 输入前缀/后缀 ──→ 实时更新
    │
    ├── 点击 [生成]
    │   └── 生成结果列表
    │       ├── 数量 ≤ 50 ──→ 直接展示
    │       └── 数量 > 50 ──→ 展示前 50 个 + "...还有 N 个"
    │
    ├── 点击单个 [复制] ──→ 复制该 UUID
    │
    ├── 点击 [复制全部] ──→ 所有 UUID 以换行分隔复制
    │
    └── 点击 [导出] ──→ 下载 .txt 文件
```

## 边界情况
- 数量为 1：不显示列表标记，单行展示
- 数量为 0 或负数：自动钳制到 1
- 数量 > 100：自动钳制到 100，或提示 "单次最多生成 100 个"
- 前缀/后缀为空：正常生成，不添加额外内容
- 前缀/后缀为特殊字符：正常拼接
- 格式切换时已有结果：提示 "格式已更改，请重新生成" 或实时转换已有结果
- 生成时浏览器不支持 crypto API：降级使用 Math.random() + 提示

## 错误处理（异常）
| 场景 | 处理方式 |
|:---|:---|
| 浏览器不支持 crypto.getRandomValues | 降级为 Math.random() 生成，提示 "使用伪随机数" |
| 复制失败 | 提示手动复制 |
| 导出失败 | 提示 "导出失败"，提供复制全部作为备选 |

## 本地存储策略
- 保存数量、格式、前缀、后缀配置
- 不保存生成的 UUID（每次生成都是新的）

## 响应式适配
- 桌面端：左右分栏，配置在左，结果在右
- 移动端：上下分栏，配置在上，结果在下，结果区可滚动
