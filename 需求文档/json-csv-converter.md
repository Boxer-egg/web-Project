# JSON ↔ CSV 转换

## 功能概述
在 JSON 数组和 CSV（逗号分隔值）格式之间进行相互转换，支持表头自定义、嵌套对象扁平化、以及导出文件。

## 输入
- 文本输入框（textarea）：输入 JSON 或 CSV
- 方向选择：JSON → CSV / CSV → JSON
- CSV 配置（JSON→CSV 时显示）：
  - 分隔符：逗号 / 分号 / Tab
  - 是否包含表头
  - 嵌套对象处理方式：扁平化 / 忽略 / 序列化为 JSON 字符串

## 操作按钮
1. **转换** — 按当前方向执行转换
2. **复制结果** — 复制输出内容
3. **导出 CSV** — 下载 .csv 文件（JSON→CSV 时）
4. **导出 JSON** — 下载 .json 文件（CSV→JSON 时）
5. **清空** — 清空输入和输出
6. **加载示例** — 填入示例数据

## 输出
- 文本输出框：展示转换结果
- 预览表格（JSON→CSV 时）：以 HTML 表格形式展示前 5 行预览
- 错误信息：转换失败时显示具体原因


## 状态流转（逻辑/交互）
```
用户进入页面
    │
    ├── 默认方向：JSON → CSV
    │
    ├── [加载示例] ──→ 填入示例 JSON 数组
    │
    ├── 用户输入 JSON/CSV
    │
    ├── 点击 [转换]
    │   ├── 方向为 JSON→CSV
    │   │   ├── 输入不是合法 JSON ──→ 提示具体错误位置
    │   │   ├── 输入不是数组 ──→ 提示 "请输入 JSON 数组"
    │   │   ├── 数组为空 ──→ 输出空表头
    │   │   └── 数组合法 ──→ 生成 CSV + 表格预览
    │   │
    │   └── 方向为 CSV→JSON
    │       ├── 输入为空 ──→ 输出空数组 []
    │       ├── 解析失败 ──→ 提示 "第 X 行列数不一致"
    │       └── 解析成功 ──→ 输出 JSON 数组
    │
    └── 点击导出 ──→ 下载对应格式文件
```

## 边界情况
- JSON 输入不是数组：提示并拒绝转换
- JSON 数组元素不是对象：将每个元素作为单行处理
- JSON 对象字段不一致：以第一个对象的字段为表头，缺失字段留空
- JSON 嵌套对象：按配置处理（扁平化时用点号连接键名，如 `user.name`）
- JSON 嵌套数组：序列化为 JSON 字符串放入单元格
- CSV 首行不是表头：用户取消 "包含表头" 时，用默认列名 `col0, col1...`
- CSV 行数列数不一致：用空值补齐，或提示具体哪一行
- CSV 含引号/换行：正确解析 RFC 4180 标准格式
- CSV→JSON 时值全是数字字符串：默认作为字符串输出，不提供自动类型转换（避免歧义）
- 大文件（>1000 行）：显示 "数据量较大，仅展示前 1000 行"

## 错误处理（异常）
| 场景 | 处理方式 |
|:---|:---|
| JSON 语法错误 | 提示 "JSON 解析失败：第 X 行附近语法错误" |
| JSON 不是数组 | 提示 "请输入 JSON 数组，例如 [{...}, {...}]" |
| CSV 列数不一致 | 提示 "第 X 行列数不匹配，已用空值补齐" |
| 导出失败 | 提示 "导出失败"，提供复制内容作为备选 |
| 复制失败 | 提示手动复制 |

## 本地存储策略
- 保存最后一次输入内容
- 保存方向选择
- 保存 CSV 配置（分隔符、表头、嵌套处理）

## 响应式适配
- 桌面端：左右分栏，表格预览在输出区下方
- 移动端：上下分栏，表格预览横向滚动
