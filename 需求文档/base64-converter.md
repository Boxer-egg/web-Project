# Base64 编解码工具

## 功能概述
实现文本与 Base64 字符串之间的相互转换，同时支持图片等文件的 Base64 编码。

## 输入
- 文本输入框（textarea）：输入普通文本或 Base64 字符串
- 文件上传区域（拖拽或点击上传）：支持图片、文本等文件

## 操作按钮
1. **文本 → Base64** — 将输入的文本编码为 Base64
2. **Base64 → 文本** — 将输入的 Base64 解码为文本
3. **文件 → Base64** — 将上传的文件转为 Base64 Data URL
4. **复制结果** — 复制输出内容
5. **清空** — 清空所有内容
6. **加载示例** — 填入示例文本

## 输出
- 文本输出框：展示编码/解码结果
- 文件预览区：若编码的是图片，展示图片预览
- 结果统计：显示字符数 / 文件大小

## 界面布局
```
+------------------+------------------+
|   输入区域        |   输出区域        |
|   (文本/文件)    |   (Base64 结果)  |
|                  |   [图片预览]      |
|   [文本→Base64]  |                  |
|   [Base64→文本]  |   [复制结果]      |
|   [文件→Base64]  |   [字符数统计]    |
|   [清空]          |                  |
|   [加载示例]      |                  |
+------------------+------------------+
```

## 功能细节
- 支持 UTF-8 编码的中文文本转 Base64
- 文件上传支持拖拽
- 大文件（>1MB）编码时显示进度提示
- 图片文件编码后可直接预览

## 状态流转
```
用户进入页面
    │
    ├── 文本模式（默认）
    │   │
    │   ├── 用户输入文本 ──→ 点击 [文本→Base64] ──→ 输出 Base64 字符串
    │   │
    │   └── 用户输入 Base64 ──→ 点击 [Base64→文本] ──→ 输出原文本
    │       └── 解码失败 ──→ 显示 "无效的 Base64 字符串"
    │
    └── 文件模式
        │
        ├── 用户拖拽文件到上传区 ──→ 或点击选择文件
        │   │
        │   ├── 文件 ≤10MB ──→ 读取并转为 Base64 Data URL
        │   │   ├── 图片文件 ──→ 输出区显示图片预览 + Base64 文本
        │   │   └── 非图片文件 ──→ 输出区显示文件信息 + Base64 文本
        │   │
        │   └── 文件 >10MB ──→ 提示 "文件过大，建议压缩后上传"
        │
        └── 用户点击 [复制结果] ──→ 复制 Base64 字符串
```

## 错误处理
| 场景 | 处理方式 |
|:---|:---|
| 输入为空时点击转换 | 提示 "请输入内容" |
| Base64 解码失败 | 显示 "输入内容不是有效的 Base64 编码" |
| 文件类型不支持 | 提示 "该文件类型可能无法正确预览，但编码仍可进行" |
| 读取文件失败 | 提示 "文件读取失败，请重试" |
| 复制失败 | 提示 "复制失败"，自动选中输出文本 |

## 边界情况
- 输入空字符串编码：输出空字符串，不报错
- 输入包含换行的 Base64（如从邮件复制）：自动去除换行和空格后解码
- 输入非 Base64 字符（如中文）：解码时给出明确错误
- 文件名为中文：正常处理，编码结果不受影响
- 拖拽多个文件：仅处理第一个，或提示 "每次仅支持一个文件"
- 粘贴 Data URL（如 `data:image/png;base64,xxx`）：识别并提取纯 Base64 部分

## 本地存储策略
- 自动保存最后一次文本输入（不含文件，文件无法存 localStorage）
- 保存当前模式（文本模式 / 文件模式）
- 页面刷新后恢复到文本模式及上次输入

## 响应式适配
- 桌面端：左右分栏，文件上传区在输入区下方
- 移动端：上下分栏，文件上传区醒目展示，支持拍照上传（调用相册）
- 图片预览在移动端全宽展示，支持点击放大
