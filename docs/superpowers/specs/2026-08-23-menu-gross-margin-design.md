# 餐饮菜单毛利率计算器 · 功能设计文档

> **定位**：与现有「餐饮盈利计算器」互补。用户在测算门店盈利时，往往需要先把菜单结构拆清楚：每道菜的成本是多少、套餐怎么定价、整体菜单毛利率落在什么区间。本工具专注于「菜品 / 套餐 / 菜单」三级毛利率的计算与聚合。

**目标用户**：准备开店、调整菜单或设计套餐的餐饮创业者/经营者。

**使用场景**：
- 研发新菜品时，快速测算单菜毛利率。
- 调整菜单结构时，查看整体菜单毛利率变化。
- 设计套餐时，基于已有菜品组合定价并测算套餐毛利率。

---

## 全局约束

- 文档只描述功能与交互，不涉及具体代码实现。
- 所有计算结果必须明确标注「基于录入成本，仅供参考」。
- 允许成本或售价为 0，表示「未定价 / 未录入」，但不参与有效统计。
- 交互风格与现有「餐饮盈利计算器」保持一致（卡片、表格、轻量弹窗、一键下载结果图）。
- 数据默认保存在浏览器本地（`localStorage`），刷新不丢失；提供清空与加载示例。

---

## 1. 核心功能

### 1.1 单品毛利率计算

**定义**：单个菜品或小吃（以下统称「单品」）的毛利率。

#### 1.1.1 单品信息

| 字段 | 必填 | 默认值 | 说明 |
|---|---|---|---|
| 单品名称 | 是 | 空 | 如：牛肉饭、尖椒鸡蛋盖饭 |
| 售价 | 是 | 0 | 该单品对外售价，单位：元 |
| 原材料清单 | 是 | 空 | 由多条原材料记录组成 |

#### 1.1.2 原材料记录

每条原材料包含：

| 字段 | 必填 | 默认值 | 说明 |
|---|---|---|---|
| 原材料名称 | 是 | 空 | 如：牛肉、米饭、青椒、鸡蛋 |
| 成本 | 是 | 0 | 该原材料在该单品中的用量成本，单位：元 |

#### 1.1.3 计算逻辑

```
单品成本 = 所有原材料成本之和
单品毛利 = 单品售价 - 单品成本
单品毛利率 = 单品毛利 ÷ 单品售价 × 100%
```

**边界规则**：
- 售价为 0 时，毛利率显示为「—」，并提示「请先填写售价」。
- 成本 ≥ 售价时，毛利率显示为「0%」或负数（保留两位小数），并给出「成本已覆盖售价」警告。

#### 1.1.4 交互规则

- 用户进入单品毛利计算区，默认有一个空的「牛肉饭」示例卡片或完全空白卡片。
- 支持「添加原材料」和「删除原材料」；删除最后一条时保留一条空记录，避免卡片为空。
- 每输入一项，卡片底部实时更新：成本合计、毛利、毛利率。
- 支持添加多个单品卡片；支持删除整个单品（需二次确认）。

---

### 1.2 整体菜单毛利率计算

**定义**：将已录入的全部单品按销售额占比加权，计算整体菜单毛利率。

#### 1.2.1 销售占比输入

对于每个已录入的单品，用户需补充：

| 字段 | 必填 | 默认值 | 说明 |
|---|---|---|---|
| 预期销量占比 | 否 | 0% | 该单品销售额占菜单总销售额的比例 |

**两种输入模式**（二选一，两种都实现）：
1. **百分比模式**：直接输入 0% ~ 100% 的占比。
2. **相对销量模式**：输入各单品的相对销量（如 A 卖 10 份、B 卖 5 份），系统自动换算为占比。

> **确认**：两种模式都需要实现，用户可在顶部一键切换。

#### 1.2.2 计算逻辑

```
加权单品毛利 = 单品毛利率 × 单品销售额占比
整体菜单毛利率 = 所有加权单品毛利之和
```

若使用相对销量模式：

```
单品销售额 = 单品售价 × 相对销量
总销售额 = 所有单品销售额之和
单品销售额占比 = 单品销售额 ÷ 总销售额
整体菜单毛利率 = Σ(单品毛利率 × 单品销售额占比)
```

#### 1.2.3 输出项

| 输出项 | 说明 |
|---|---|
| **整体菜单毛利率** | 加权后的综合毛利率 |
| 菜单总成本 | 所有单品成本 × 销量后加总 |
| 菜单总销售额 | 所有单品售价 × 销量后加总 |
| 各单品贡献占比 | 列表展示，帮助识别高贡献/低贡献单品 |

### 1.3 套餐功能

**定义**：将已录入的若干个单品组合成套餐，并设置套餐售价，自动计算套餐毛利率。

#### 1.3.1 套餐信息

| 字段 | 必填 | 默认值 | 说明 |
|---|---|---|---|
| 套餐名称 | 是 | 空 | 如：招牌双人餐、商务套餐 |
| 套餐售价 | 是 | 0 | 套餐对外售价，单位：元 |
| 包含单品 | 是 | 空 | 从已有单品列表中勾选 |

#### 1.3.2 套餐成本与毛利

```
套餐成本 = 所选单品成本之和
套餐毛利 = 套餐售价 - 套餐成本
套餐毛利率 = 套餐毛利 ÷ 套餐售价 × 100%
```

#### 1.3.3 套餐定价辅助

- 展示「按单品原价合计」与「套餐售价」的对比。
- 计算并展示「套餐折扣率 = 套餐售价 ÷ 单品原价合计 × 100%」。
- 提供建议：若折扣率低于常见阈值（如 70%），提示「折扣力度较大，请确认毛利是否可接受」。

#### 1.3.4 交互规则

- 创建套餐时，从左侧或下拉列表中选择已录入的单品。
- 支持为每个单品设置「是否默认包含」；默认全部包含。
- 套餐卡片实时显示：成本、原价合计、售价、折扣率、毛利、毛利率。
- 支持编辑、删除套餐；删除前需二次确认。

## 2. 页面结构建议

### 2.1 三大区域

1. **单品管理区**：
   - 顶部操作栏：添加单品、加载示例、清空全部。
   - 下方为单品卡片列表，每个卡片包含原材料表格和实时计算结果。

2. **套餐设计区**：
   - 顶部「添加套餐」按钮。
   - 套餐卡片列表，每个卡片展示所选单品与套餐定价结果。

3. **整体菜单毛利率区**：
   - 汇总所有单品与套餐的销售数据。
   - 提供百分比 / 相对销量两种输入切换。
   - 底部展示整体菜单毛利率与可视化饼图/条形图。

### 2.2 数据联动

- 单品数据变化时，自动同步到套餐（引用了该单品的套餐成本/毛利率联动更新）。
- 单品数据变化时，整体菜单毛利率区自动重新计算。
- **套餐默认不参与整体菜单毛利率计算**，避免单品与套餐重复统计；如需将套餐作为虚拟单品参与，可在整体菜单毛利率区手动开启「套餐参与统计」开关（默认关闭）。

## 3. 辅助功能

### 3.1 加载示例

一键加载一组示例数据：
- 单品：牛肉饭（成本 12 元，售价 28 元）、尖椒鸡蛋盖饭（成本 6 元，售价 18 元）、凉拌黄瓜（成本 2 元，售价 8 元）。
- 套餐：招牌双人餐（含牛肉饭×2 + 凉拌黄瓜×1，售价 58 元）。
- 销量占比：牛肉饭 50%、尖椒鸡蛋盖饭 30%、凉拌黄瓜 20%。

### 3.2 清空全部

重置所有单品、套餐和销量占比为默认值，操作前需二次确认。

### 3.3 下载结果图片

将当前菜单毛利率汇总结果生成图片，便于分享或保存。

### 3.4 导出 Excel

支持将以下数据导出为 `.xlsx` 文件：
- 所有单品：名称、售价、成本、毛利、毛利率。
- 所有套餐：名称、包含单品、套餐售价、成本、毛利、毛利率、折扣率。
- 整体菜单毛利率汇总：各单品销售额占比、加权贡献、综合毛利率。

### 3.5 与「餐饮盈利计算器」打通

- 提供「将整体菜单毛利率回填到餐饮盈利计算器」按钮，自动跳转到 `/tools/restaurant-profit` 并把计算出的毛利率写入对应字段。

### 3.6 菜单方案保存

支持将当前所有单品、套餐、销量占比、整体设置保存为一份**命名菜单方案**，例如：
- 夏季菜单
- 冬季菜单
- 工作日套餐菜单
- 节假日特惠菜单

**功能规则**：
- 顶部提供「当前方案」下拉选择 + 新建 / 重命名 / 删除按钮。
- 新建方案时，默认复制当前方案数据，或从空白开始。
- 切换方案时自动保存当前方案修改（或提示未保存）。
- 所有方案数据保存在浏览器本地（`localStorage`）。
- 默认至少保留一个「默认菜单」方案，不可删除。

## 4. 计算示例

### 4.1 单品示例

| 单品 | 售价 | 原材料 | 成本 |
|---|---|---|---|
| 牛肉饭 | 28 元 | 牛肉 10 元 + 米饭 1 元 + 配菜 1 元 | 12 元 |

```
单品毛利 = 28 - 12 = 16 元
单品毛利率 = 16 ÷ 28 × 100% = 57.14%
```

### 4.2 整体菜单示例

| 单品 | 售价 | 成本 | 毛利率 | 销量占比 |
|---|---|---|---|---|
| 牛肉饭 | 28 | 12 | 57.14% | 50% |
| 尖椒鸡蛋盖饭 | 18 | 6 | 66.67% | 30% |
| 凉拌黄瓜 | 8 | 2 | 75.00% | 20% |

```
整体菜单毛利率 = 57.14% × 50% + 66.67% × 30% + 75.00% × 20%
              = 28.57% + 20.00% + 15.00%
              = 63.57%
```

### 4.3 套餐示例

| 套餐 | 包含单品 | 单品原价合计 | 套餐售价 |
|---|---|---|---|
| 招牌双人餐 | 牛肉饭 × 2 + 凉拌黄瓜 × 1 | 28 × 2 + 8 = 64 元 | 58 元 |

```
套餐成本 = 12 × 2 + 2 = 26 元
套餐毛利 = 58 - 26 = 32 元
套餐毛利率 = 32 ÷ 58 × 100% = 55.17%
折扣率 = 58 ÷ 64 × 100% = 90.63%
```

## 5. 异常与边界处理

| 场景 | 处理方式 |
|---|---|
| 单品售价为 0 | 毛利率显示「—」，提示填写售价 |
| 单品成本 ≥ 售价 | 毛利率显示 0% 或负数，给出成本警告 |
| 所有单品销量占比为 0 | 整体菜单毛利率显示「—」，提示录入销量占比 |
| 销量占比之和不等于 100% | 实时显示「当前占比合计 XX%」并提供「一键归一」按钮 |
| 套餐包含已删除单品 | 套餐卡片标红提示「包含已删除单品，请重新选择」 |
| 套餐售价为 0 | 套餐毛利率显示「—」，提示填写售价 |

## 6. 已确认决策

| 问题 | 决策 |
|---|---|
| 套餐是否参与整体菜单毛利率计算？ | **默认不参与**；整体菜单毛利率区提供可选开关，手动开启后套餐才作为虚拟单品参与。 |
| 销量占比支持哪些模式？ | **百分比 + 相对销量两种模式都实现**，顶部提供切换按钮。 |
| 计算结果导出格式？ | **支持导出 Excel（.xlsx）**；同时保留现有的下载结果图片功能。 |
| 是否需要内置常见原材料库？ | **当前阶段不需要**；用户完全手动录入原材料名称和成本。 |
| 是否支持保存多份菜单？ | **支持命名保存多份菜单方案**（如夏季菜单、冬季菜单），提供新建/重命名/删除/切换功能。 |
