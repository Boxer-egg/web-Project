# CSS 单位转换

## 功能概述
在常见的 CSS 长度单位之间进行相互转换（PX、REM、EM、VH、VW、百分比等），支持基于根字体大小和父元素字体大小的精确计算。

## 输入
1. **数值输入**：要转换的数字
2. **源单位**：PX / REM / EM / VH / VW / % / PT / PC / IN / CM / MM
3. **目标单位**：多选（可同时查看多个单位的转换结果）
4. **根字体大小**：默认 16px（影响 PX↔REM 转换）
5. **父元素字体大小**：默认 16px（影响 PX↔EM 转换）
6. **视口宽度**：默认 1920px（影响 PX↔VW 转换）
7. **视口高度**：默认 1080px（影响 PX↔VH 转换）

## 操作按钮
1. **转换** — 按配置计算所有目标单位
2. **复制结果** — 复制指定单位的 `值+单位` 形式
3. **复制全部** — 复制所有结果的 CSS 变量形式
4. **清空** — 清空输入
5. **加载示例** — 填入示例值

## 输出
- 结果列表：每个目标单位一行
  - 格式：`16px = 1rem`（基于根字体 16px）
- 常用对照表：展示预设的常用屏幕尺寸下的换算

## 状态流转（逻辑/交互）
```
用户进入页面
    │
    ├── 默认：数值 16，源单位 PX，目标全选
    │
    ├── [加载示例] ──→ 填入示例值
    │
    ├── 用户输入数值
    │   └── 输入时实时转换（防抖 200ms）
    │
    ├── 用户调整基础配置（根字体/父字体/视口尺寸）
    │   └── 如有数值，实时重新计算
    │
    ├── 点击 [转换]
    │   ├── 数值为空 ──→ 输出空
    │   ├── 数值非数字 ──→ 提示 "请输入有效数字"
    │   └── 正常 ──→ 展示所有目标单位结果
    │
    └── 点击复制 ──→ 复制带单位的值
```

## 边界情况
- 输入为 0：所有单位转换结果都为 0
- 输入负数：支持负数，用于 CSS 的负值场景
- 输入小数：保留 4 位小数，末尾 0 可省略
- 输入非数字：提示 "请输入有效数字"
- 根字体为 0：提示 "根字体大小不能为 0"，REM 转换不显示
- 父字体为 0：提示 "父字体大小不能为 0"，EM 转换不显示
- 视口宽/高为 0：提示 "视口尺寸不能为 0"，VH/VW 转换不显示
- 百分比转换：基于父元素宽度（默认 100% = 父元素宽度），提示 "百分比基于父元素宽度计算"
- 绝对单位（IN/CM/MM）：基于标准换算 1in = 96px

## 错误处理（异常）
| 场景 | 处理方式 |
|:---|:---|
| 输入为空 | 输出为空 |
| 输入非数字 | 提示 "请输入有效数字" |
| 根字体/父字体/视口为 0 | 提示 "该值不能为 0"，对应单位不显示结果 |
| 复制失败 | 提示手动复制 |

## 本地存储策略
- 保存数值、源单位、目标单位选择
- 保存根字体、父字体、视口尺寸配置

## 响应式适配
- 桌面端：左右分栏，基础配置在输入区下方折叠展示
- 移动端：上下分栏，基础配置可折叠/展开
