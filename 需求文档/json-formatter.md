# JSON 格式化工具

## 功能概述
将用户粘贴的 JSON 字符串进行格式化、压缩或转义处理，方便阅读和调试。

## 输入
- 一个多行文本输入框（textarea）
- 支持粘贴大段 JSON 文本

## 操作按钮
1. **格式化** — 将 JSON 按层级缩进排版
2. **压缩** — 移除所有空白字符，变成一行
3. **转义** — 将 JSON 字符串中的特殊字符进行转义（如 `"` → `\"`）
4. **去转义** — 将转义后的字符串还原
5. **复制结果** — 将输出框内容复制到剪贴板
6. **清空** — 清空输入和输出
7. **加载示例** — 填入一段示例 JSON 数据

## 输出
- 一个多行文本输出框，展示处理后的结果
- 若输入非合法 JSON，输出错误提示（如 "第 15 行缺少逗号"）

## 界面布局
```
+------------------+------------------+
|   输入区域        |   输出区域        |
|   (JSON 原文)    |   (处理后结果)    |
|                  |                  |
|   [格式化]        |   [复制结果]      |
|   [压缩]          |                  |
|   [转义]          |                  |
|   [去转义]        |                  |
|   [清空]          |                  |
|   [加载示例]      |                  |
+------------------+------------------+
```

## 功能细节
- 格式化缩进默认 2 个空格，可切换 4 空格 / Tab
- 支持解析错误时显示具体错误位置和原因
- 格式化后可展开/折叠节点（如需要可后续迭代）

## 状态流转
```
用户进入页面
    │
    ▼
输入框为空 ──→ [加载示例] ──→ 填入示例 JSON
    │
    ▼
用户粘贴/输入 JSON
    │
    ├── 输入过程中实时校验（防抖 300ms）
    │   ├── 合法 JSON ──→ 右下角显示 "✓ 格式正确"（绿色）
    │   └── 非法 JSON ──→ 显示错误提示（红色，含行号）
    │
    ▼
用户点击 [格式化]/[压缩]/[转义]/[去转义]
    │
    ▼
输出框展示结果
    │
    ├── 用户点击 [复制结果] ──→ 复制到剪贴板，按钮文字变 "已复制" 2 秒后恢复
    └── 用户继续修改输入 ──→ 输出框实时更新（无需再次点击按钮）
```

## 错误处理
| 场景 | 处理方式 |
|:---|:---|
| 输入为空时点击按钮 | 输出框显示 "请输入 JSON 内容"，不报错 |
| JSON 语法错误 | 显示具体错误信息，如 "第 3 行，第 8 列：Unexpected token '}'" |
| 转义/去转义非 JSON 文本 | 正常执行文本级转义，不做 JSON 校验 |
| 超大 JSON（>1MB） | 格式化时显示 "处理中..."，避免页面卡死 |
| 复制失败（权限问题） | 提示 "复制失败，请手动复制"，并自动选中输出框内容 |

## 边界情况
- 输入纯数字（如 `123`）：合法 JSON，格式化后仍为 `123`
- 输入 JSON 字符串（如 `"hello"`）：合法 JSON，格式化后仍为 `"hello"`
- 输入 `null` / `true` / `false`：合法 JSON，正常处理
- 输入包含中文的 JSON：正确显示，不转义中文
- 输入包含 emoji 的 JSON：正确显示和格式化
- 输入框最大容量：建议限制 5MB 文本，超限提示 "内容过大"

## 本地存储策略
- 自动保存用户最后一次输入的 JSON 文本到 `localStorage`
- 保存缩进偏好（2 空格 / 4 空格 / Tab）
- 页面刷新后自动恢复上次输入内容
- 提供 "清除历史" 按钮（可选，首批可不做）

## 响应式适配
- **桌面端（≥768px）**：左右分栏，输入输出各占 50%
- **移动端（<768px）**：上下分栏，输入在上，输出在下，按钮横排滚动或折叠
- 文本框高度：桌面端固定 500px，移动端自适应屏幕高度的 40%
