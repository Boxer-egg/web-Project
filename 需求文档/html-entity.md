# HTML 实体编解码

## 功能概述
将 HTML 特殊字符与对应的实体编码互相转换，支持 Named Entities（如 `&lt;`）和 Numeric Entities（如 `&#60;` / `&#x3C;`）。

## 输入
- 多行文本输入框（textarea）：输入 HTML 源码或含实体编码的文本

## 操作按钮
1. **编码 → Named** — 将特殊字符转为命名实体（如 `<` → `&lt;`）
2. **编码 → Numeric** — 将特殊字符转为数字实体（如 `<` → `&#60;`）
3. **编码 → Hex** — 将特殊字符转为十六进制实体（如 `<` → `&#x3C;`）
4. **解码** — 将所有实体编码还原为原始字符
5. **复制结果** — 复制输出内容
6. **清空** — 清空输入和输出
7. **加载示例** — 填入一段含特殊字符的示例 HTML

## 输出
- 多行文本输出框，展示编码/解码结果
- 常见实体速查表（下方展示常用对照）

## 界面布局
```
+------------------+------------------+
|   输入区域        |   输出区域        |
|   (原始/实体)    |   (处理后结果)    |
|                  |                  |
|   [编码→Named]   |   [复制结果]      |
|   [编码→Numeric] |                  |
|   [编码→Hex]     |                  |
|   [解码]         |                  |
|   [清空]         |                  |
|   [加载示例]     |                  |
+------------------+------------------+
|           常用实体速查表              |
|   < → &lt;    > → &gt;    & → &amp;  |
|   " → &quot;  ' → &#x27;   空格 → &nbsp; |
+-------------------------------------+
```

## 状态流转（逻辑/交互）
```
用户进入页面
    │
    ├── [加载示例] ──→ 填入含特殊字符的 HTML 示例
    │
    └── 用户输入文本
        │
        ├── 点击 [编码→Named]
        │   └── 仅编码核心 HTML 字符（< > & " '）
        │       └── 可选择是否编码所有非 ASCII 字符
        │
        ├── 点击 [编码→Numeric]
        │   └── 所有非 ASCII 字符转为 &#NNNN; 格式
        │
        ├── 点击 [编码→Hex]
        │   └── 所有非 ASCII 字符转为 &#xNNNN; 格式
        │
        ├── 点击 [解码]
        │   ├── 识别 Named Entities（&lt; &gt; &amp; 等）
        │   ├── 识别 Decimal Entities（&#60;）
        │   └── 识别 Hex Entities（&#x3C;）
        │   └── 混合编码可一次性全部解码
        │
        └── 点击 [复制结果] ──→ 复制到剪贴板
```

## 边界情况
- 输入不含任何需要编码的字符：输出与输入相同
- 输入已经是实体编码：再次编码时不会双重编码（即 `&lt;` 不会再变成 `&amp;lt;`）
- 输入含非法实体格式（如 `&invalid;`）：解码时保持原样，不报错
- 输入含未闭合的 `&`：保持原样，不报错
- 输入纯数字实体 `&#12345;`：正确解码为对应 Unicode 字符
- 输入超出 Unicode 范围的实体：保持原样，提示 "包含无法解码的实体"
- 输入空字符串：输出空字符串
- 编码全部非 ASCII 选项：中文字符也会被编码为实体

## 错误处理（异常）
| 场景 | 处理方式 |
|:---|:---|
| 输入为空时点击操作 | 输出空字符串，不报错 |
| 解码时遇到格式错误的实体 | 保持原样不转换，不报错 |
| 编码/解码后结果与输入相同 | 正常输出，不提示 |
| 复制失败 | 提示手动复制 |

## 本地存储策略
- 保存最后一次输入的文本
- 保存编码模式偏好（Named/Numeric/Hex）
- 保存 "编码所有非 ASCII" 选项状态

## 响应式适配
- 桌面端：左右分栏，速查表在输出区下方
- 移动端：上下分栏，速查表可横向滑动
