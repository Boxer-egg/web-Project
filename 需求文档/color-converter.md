# 颜色转换器

## 功能概述
在 HEX、RGB、HSL 等常见颜色格式之间进行转换，提供实时预览和调色板功能。

## 输入
1. 颜色输入框：支持多种格式输入
   - HEX: `#FF5733` 或 `FF5733`
   - RGB: `rgb(255, 87, 51)` 或 `255, 87, 51`
   - HSL: `hsl(9, 100%, 60%)`
2. 颜色选择器（原生 color picker）：可视化选色

## 操作按钮
1. **复制 HEX** — 复制 HEX 值
2. **复制 RGB** — 复制 RGB 值
3. **复制 HSL** — 复制 HSL 值
4. **随机颜色** — 生成一个随机颜色并展示
5. **清空** — 清空输入

## 输出
- 颜色预览块：大面积展示当前颜色
- 各格式输出（只读，实时同步）：
  - HEX: `#FF5733`
  - RGB: `rgb(255, 87, 51)`
  - HSL: `hsl(9, 100%, 60%)`
- 配色建议：展示当前颜色的深色/浅色变体

## 界面布局
```
+------------------+------------------+
|   颜色预览块      |   颜色输入        |
|   (大面积色块)   |   HEX: [#     ]  |
|                  |   RGB: [ , , ]   |
|   [随机颜色]      |   HSL: [ ,%,%]   |
|                  |   [颜色选择器]    |
|   配色建议        |                  |
|   [深色] [浅色]   |   [复制HEX]       |
|   [更亮] [更暗]   |   [复制RGB]       |
|                  |   [复制HSL]       |
+------------------+------------------+
```

## 功能细节
- 输入任意格式时，其他格式实时同步更新
- 颜色预览块支持点击复制颜色值
- 提供当前颜色的渐变变体（更亮、更暗）
- 自动识别输入格式并解析

## 状态流转
```
用户进入页面
    │
    ├── 默认显示一个预设颜色（如 #3B82F6 蓝色）
    │
    ├── 用户修改 HEX 输入
    │   ├── 输入合法（如 #FF5733）──→ RGB/HSL 实时更新，预览块变色
    │   └── 输入不合法 ──→ 输入框边框变红，其他字段不更新
    │
    ├── 用户修改 RGB 输入（三个数字输入框）
    │   └── 任一值变化 ──→ HEX/HSL 实时更新
    │
    ├── 用户修改 HSL 输入
    │   └── 任一值变化 ──→ HEX/RGB 实时更新
    │
    ├── 用户点击颜色选择器
    │   └── 选择颜色 ──→ 所有输入框同步更新
    │
    ├── 用户点击 [随机颜色]
    │   └── 生成随机颜色 ──→ 所有字段更新
    │
    └── 用户点击预览块或 [复制XX]
        └── 复制对应格式到剪贴板，按钮提示 "已复制"
```

## 错误处理
| 场景 | 处理方式 |
|:---|:---|
| HEX 输入不合法（如 `#GGG`） | 输入框边框变红，下方提示 "无效的 HEX 颜色"，其他字段保持上次有效值 |
| RGB 输入超出范围（如 256, -1） | 自动钳制到 0~255，或提示 "数值应在 0-255 之间" |
| HSL 输入超出范围 | 自动钳制，Hue 0~360，Saturation/Lightness 0%~100% |
| 输入框为空 | 不更新其他字段，保持当前颜色 |

## 边界情况
- 输入 3 位 HEX（如 `#F0F`）：自动扩展为 6 位 `#FF00FF`
- 输入不带 `#` 的 HEX（如 `FF5733`）：自动补 `#`
- 输入带透明度的 HEX（如 `#FF573380`）：支持解析，但 RGB/HSL 不显示 Alpha（或可选显示）
- RGB 输入小数（如 `255.5`）：四舍五入取整
- 颜色选择器不支持的颜色：回退到最近的合法值
- 配色建议生成规则：
  - 深色变体：Lightness 减少 20%
  - 浅色变体：Lightness 增加 20%
  - 更亮：Lightness +30%
  - 更暗：Lightness -30%

## 本地存储策略
- 保存用户最后使用的颜色
- 保存最近使用的 5 个颜色（可选，显示为色板）

## 响应式适配
- 桌面端：左右分栏，预览块在左（大面积），输入区在右
- 移动端：上下布局，预览块在上（占屏幕 30% 高度），输入区在下
- RGB/HSL 的三个输入框在移动端横排，宽度均分
